# QUADRIDGE v0.2

## 1. 配置不能時の処理

現在表示されている3つのブロック候補がすべて配置不能の場合、その手番は**パス**する。

配置不能とは、各候補についてすべての回転状態を試しても、盤面上のどこにも合法的に配置できない状態を指す。

### パス発生時の処理

1. その手番ではブロックを配置しない
2. 手番をパスする
3. 現在の盤面状態から、配置可能なブロック形状を判定する
4. 配置可能な形状のみを対象として候補をリロールする
5. 相手プレイヤーの手番へ移行する
6. 次回の自分の手番では、リロール後の候補を使用する

通常時は7種1巡方式を維持し、配置不能時のみ例外的にリロール処理を行う。

盤面に配置できるブロックが存在する限り、可能な限りゲームを継続する。

### 配置可能な形状が少ない場合

現在の盤面に配置可能な形状が3種類未満しか存在しない場合は、存在する配置可能形状のみを候補として扱う。

7種類すべてについて、すべての回転状態を含めても盤面上のどこにも配置できなくなった場合の最終的な処理は未決定とする。

## 2. ブロック候補の操作

画面手前に表示されている3つのブロック候補は、キーボードの **A / Dキー** で選択する。

- **Aキー：左の候補へ移動**
- **Dキー：右の候補へ移動**

選択中のブロック候補は、浮き上がり・拡大・強調表示などによって、現在選択されていることが分かるようにする。

3候補の端からさらに外側へ入力した場合の挙動は未決定。

---

## 3. ブロックの回転操作

配置するブロックの回転は、キーボードの **Q / Eキー** で行う。

- **Qキー：左回転（反時計回りに90度）**
- **Eキー：右回転（時計回りに90度）**

回転回数に制限はない。

### 回転アニメーション

QまたはEキーを入力した際、ブロックの向きを瞬間的に切り替えるのではなく、入力方向に合わせて**90度回転する短いアニメーション**を再生する。

- Q入力時：左方向へ回転
- E入力時：右方向へ回転

操作テンポを損なわない程度の短い演出とする。

## 4. 画面サイズへの自動対応

ゲーム画面は、使用しているウィンドウサイズや画面解像度に応じて自動的にスケーリングする。

通常のゲームプレイ中は、**縦・横ともにスクロールを発生させないことを基本方針とする。**

15×15の盤面、3つのブロック候補、その他必要なUIを含めたゲーム画面全体が、現在の表示領域内に収まるようにサイズを自動調整する。

ウィンドウサイズが変更された場合も、リアルタイムで表示サイズを再計算する。

### スケーリング条件

- 15×15盤面全体が画面内に収まる
- 盤面の各マスは正方形を維持する
- 盤面の縦横比を維持する
- 手前の3つのブロック候補も同一画面内に表示する
- UI同士が重ならないようにする
- 縦スクロールを原則発生させない
- 横スクロールを原則発生させない
- ウィンドウサイズ変更に追従する
- 利用可能な縦幅・横幅のうち、より制約の大きい方を基準としてサイズを調整する

極端に小さなウィンドウについても可能な限り縮小表示するが、文字や操作性を維持できないサイズでの具体的な対応は未決定。

## v0.2 変更概要

v0.2では以下を追加した。

- 3候補すべてが配置不能な場合のパス処理
- 配置可能なブロックのみを対象とするリロール処理
- 盤面に置ける限りゲームを継続する方針
- A / Dキーによる3択ブロックの選択
- Q / Eキーによる左右90度回転
- 回転方向に対応した回転アニメーション
- ウィンドウサイズに応じたゲーム画面の自動スケーリング
- 通常プレイ中にスクロールを発生させないUI方針
