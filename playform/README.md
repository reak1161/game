# PLAYFORM — 遊びの手ざわり。

Webゲーム向けの、操作できるデザイン見本帳。第1〜5集に画面見本45案。第6・7集は、ゲームにコピーして使えるUI部品計10種・外観6種・動き5種を組み合わせて試せます。

## 起動

`index.html`（第1集）、`games.html`（第2集）、`quiet.html`（第3集）、`objects.html`（第4集）、`more.html`（第5集）、`parts.html`（第6集）、`game-parts.html`（第7集）をブラウザで直接開くだけで動作します。画像はローカルの `assets/` に含めています。外部フォント・CDN・実行時ライブラリ・APIへの依存はありません。上部のリンクから集を切り替えられます。

ローカルサーバーで見る場合:

```powershell
cd D:\programming\game\playform
npm start
```

http://127.0.0.1:4177 を開きます。最新の第7集は http://127.0.0.1:4177/game-parts.html 。ポートの変更は `PORT` 環境変数で指定できます。開発検証は `npm install` 後に `npm run check`。構文と22テストを確認します。happy-domはテスト専用で、配布部品には含めません。

## 設計・実装

- フレームワークなしの HTML / CSS / JavaScript。`app.js` の `studies` が一覧・解説、各 `render…` 関数が独立した試作です。
- SVGイラストはすべてインライン。紙の質感のみCSSの軽量なSVGノイズを使用します。
- 動きの自動ループは設けず、ユーザーの入力に応じて有限時間だけ再生します。
- リセット・別サンプルへの移動時はタイマーとWeb Animationsを破棄します。
- `prefers-reduced-motion` と画面右上の「動きを抑える」に対応。抑制時も操作結果と状態通知は残ります。
- ボタンはキーボード操作可。選択は `aria-pressed`、スイッチは `aria-checked`、結果は `aria-live` で伝えます。
- 第1・2集はスマートフォンでも操作できるよう、一覧・装備・切符・郵便画面などを組み替えています。第3〜7集はPC向けです。

## 自分のゲームへ移すとき

色やフォントだけでなく、「何を扱う画面なのか」「操作すると何が確定するのか」をセットで採用するのがおすすめです。CSSはサンプルのルートクラスで分けています。共通の `.solid-btn` 等と `svg` / `animate` / `later` などの補助関数も併せて取り出してください。
