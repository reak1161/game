# 1. Version 0.2.5 更新概要

Version 0.2.5では、主に以下を追加・変更する。

- ゲーム開始時に追加スキル選択を追加
- 5の倍数レベルで「アビリティ抽選 → スキル抽選」に変更
- スキル枠を Q / E / C の最大3枠へ拡張
- ショップで1枠に複数個の商品が並ぶ仕様を追加
- 新ショップアイテム3種を追加
- 新スキル3種を追加
- 新アビリティ2種を追加

---

# 2. ゲーム開始時のスキル選択

従来Lv5で行っていた追加スキル選択を、

**ゲーム開始時**

へ前倒しする。

ゲーム開始時点で、

- Q：初期固有スキル
- E：ゲーム開始時に選択する追加スキル

を所持した状態で開始する。

これにより、序盤からスキルを複数使用できるようにし、戦闘の爽快感を高める。

---

# 3. レベルアップ抽選

5の倍数レベルでは、

```text
アビリティ抽選
↓
スキル抽選
```

の順番で選択を行う。

対象：

```text
Lv5
Lv10
Lv15
Lv20
Lv25
```

5の倍数以外では、通常通りアビリティ抽選のみ行う。

---

# 4. レベルアップ選択キュー

既存のFIFO方式を維持する。

例：

Lv5到達時に、

```text
Lv5 アビリティ選択
↓
Lv5 スキル選択
```

がキューへ追加される。

未選択のままLv6へ到達した場合、

```text
Lv5 アビリティ
↓
Lv5 スキル
↓
Lv6 アビリティ
```

の順で処理する。

---

# 5. スキル枠

アウトローが所持できるアクティブスキル枠を、

```text
Q
E
C
```

の最大3枠とする。

基本構成：

```text
Q：初期固有スキル
E：ゲーム開始時に選択する追加スキル
C：後続のスキル抽選で取得可能
```

---

# 6. スキル枠が埋まった後

Q / E / Cの3枠がすべて埋まっている場合でも、5の倍数レベルではスキル抽選を行える。

この場合の候補は、

- 既存スキル強化
- 派生スキル
- 上位スキル
- スキル置換

等を中心とする。

詳細な候補生成ルールは今後拡張する。

---

# 7. ショップの商品在庫

ショップの商品枠には、まれに、

**同じ商品が複数個**

並ぶことがある。

例：

```text
1枠
商品：ポーション
在庫：3個
```

1枠につき1商品IDを持ち、在庫数を複数持てる構造とする。

# 13. 新スキル「ダイヤモンドダスト」

```text
名称：ダイヤモンドダスト
CD：15秒
```

前方、

```text
角度：45°
射程：6
```

の扇形範囲へ氷の粒を発射する。

---

# 14. ダイヤモンドダストの弾

発射数：

```text
合計30発
```

各粒は扇形内のランダム方向へ発射される。

```text
弾速：9/s
```

命中した敵へ、

```text
❄6ダメージ
```

を与える。

---

# 15. 新スキル「ライトニングリレー」

```text
名称：ライトニングリレー
CD：10秒
```

雷を中継する装置を設置する。

---

# 16. ライトニングリレーの設置

装置は、

```text
射程7以内
```

の任意地点へ設置可能。

装置サイズ：

```text
0.7
```

---

# 17. ライトニングリレーの設置プレビュー

スキル入力中は、

- 設置地点の円
- 使用者から設置地点までの軌跡

をプレビュー表示する。

設置可能距離を超えた場合は、最大射程位置へ制限する等の一般的な設置UIを使用する。

---

# 18. リレーの生成

フィールド上に装置が2個以上存在する場合、

**存在するすべての装置同士を接続する。**

接続本数は、

```text
2個 → 1本
3個 → 3本
4個 → 6本
```

となる。

---

# 19. リレーの形成

雷は各装置から相手側へ、

```text
17/s
```

の速度で伸びる。

2つの装置間の中心地点で両側の雷が接続される。

---

# 20. リレー形成中の攻撃判定

雷が形成途中の場合でも、

**すでに生成されている雷部分には攻撃判定が存在する。**

完成後と同じ効果を与える。

---

# 21. リレーの攻撃

リレー幅：

```text
約0.3
```

接触した敵へ、

```text
0.5秒ごと
⚡7ダメージ
```

を与える。

さらに、

```text
移動速度 -70%
```

を与える。

---

# 22. 装置寿命

ライトニングリレーの装置は、

```text
設置から30秒
```

で消滅する。

装置が消滅した場合、その装置に接続されていた雷も消滅する。

---

# 23. 新アビリティ「バブリンガル」

```text
名称：バブリンガル
```

自分の周囲を強力な泡が回転する防御アビリティ。

---

# 24. バブリンガルの泡

泡サイズ：

```text
0.3
```

回転方向：

```text
時計回り
```

回転速度：

```text
毎秒30°
```

---

# 25. バブリンガルの防御効果

泡に接触した、

**遠距離系攻撃**

を無効化する。

泡自体には通常の攻撃ダメージ判定を持たせない。

---

# 26. 新アビリティ「漂う鬼火」

```text
名称：漂う鬼火
```

自分の周囲を漂う鬼火を生成する。

通常時、鬼火には敵への命中判定を持たせない。

---

# 27. 漂う鬼火の索敵

鬼火は、

```text
使用者から半径3付近
```

の敵を自動で攻撃対象として探す。

具体的な優先順位は今後必要に応じて定義する。

---

# 28. 漂う鬼火の攻撃

対象を発見すると、

```text
速度：25/s
```

で対象へ突進する。

命中した敵へ、

```text
🔥6ダメージ
```

を与える。

---

# 29. 漂う鬼火の帰還

命中後、鬼火は同じく、

```text
25/s
```

で使用者の周囲へ戻る。

---

# 30. 漂う鬼火の攻撃CD

攻撃CD：

```text
1秒
```

ただし、CDが終了していても鬼火が帰還途中の場合は再攻撃しない。

再攻撃条件：

```text
攻撃CD完了
AND
使用者の周囲へ帰還完了
```

の両方を満たすこと。
