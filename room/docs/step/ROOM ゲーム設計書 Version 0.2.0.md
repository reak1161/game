# ROOM ゲーム設計書
## Version 0.2.0

> Game Title: **ROOM**  
> Full Title: **Royale Of Outlaws & Monsters**  
> Version: **0.2.0**  
> Status: Draft / 拡張前提

---

# 1. Version 0.2.0 更新概要

Version 0.2.0では、主に以下を追加・変更する。

- マップを100×100へ拡張
- 1画面固定型からスクロール可能な広域マップへ変更
- 射撃訓練場を追加
- デコイによるダメージ・DPS計測を追加
- 訓練場専用の管理画面を追加
- ボスシステムの初期実装
- 仮ボス「ヘルブレイド」を追加
- 「攻撃間隔」の用語を「攻撃CD」へ変更
- ボスのコイン報酬仕様を追加
- 近接モンスター攻撃の予兆表示を追加
- 近接モンスターの攻撃発生前に0.2秒の猶予を追加

---

# 2. マップ拡張

従来は、プレイヤーが現在の画面内に収まる範囲のみを移動できる構造だった。

Version 0.2.0ではこれを変更し、

```text
マップサイズ：100 × 100
```

の広域マップを生成する。

---

# 3. カメラ

プレイヤーは画面外の領域へ自由に移動できる。

カメラは、

```text
操作中のアウトローを追従
```

する。

そのため、100×100のマップ全体を一度に表示する必要はない。

---

# 4. 距離単位

既存の距離単位はそのまま使用する。

基準：

```text
アウトローの標準当たり判定直径 = 1.0
```

したがって、

```text
射程5
半径10
探知範囲13
```

等の既存数値は、そのまま100×100マップ内でも使用する。

---

# 5. 全体マップ

Mキーで開く全体マップも、

```text
100 × 100
```

の広域マップを基準に表示する。

今後、

- ショップ
- ボス出現地点
- 発見済み地点
- 強モンスター
- その他重要地点

等を表示可能にする。

---

# 6. 射撃訓練場

通常試合とは別に、

**射撃訓練場**

を追加する。

射撃だけでなく、

- 近接攻撃
- スキル
- アビリティ
- バフ
- ビルド
- DPS

等を自由に検証できるテストモードとして扱う。

---

# 7. デコイ

訓練場には、

```text
動かないモンスター相当のデコイ
```

を配置する。

デコイは通常の敵と同様に攻撃判定対象となる。

ただし、

```text
移動しない
攻撃しない
```

ことを基本とする。

---

# 8. デコイのダメージ計測

デコイへ攻撃した場合、少なくとも以下を確認できるようにする。

```text
総ダメージ
DPS
```

追加表示候補：

```text
最大単発ダメージ
クリティカル回数
ヒット数
計測時間
```

これらは訓練・ビルド比較に利用する。

---

# 9. DPS

DPSは、

```text
総ダメージ ÷ 計測時間
```

を基本として算出する。

攻撃を開始したタイミングから計測を開始し、必要に応じてリセット可能とする。

---

# 10. 訓練場管理画面

射撃訓練場では、

**専用の管理画面**

を開くことができる。

この画面から、通常試合では変更できない各種設定を自由に変更可能とする。

---

# 11. 管理画面で変更可能な項目

最低限、

```text
アウトロー
レベル
Qスキル
Eスキル
所持アビリティ
アビリティスタック
```

を自由に変更可能とする。

将来的には、

```text
アイテム付与
HP回復
CDリセット
状態異常付与
デコイ初期化
各種ステータス変更
```

等も追加可能。

---

# 12. 訓練場の目的

射撃訓練場は、

```text
ビルド確認
スキル挙動確認
DPS比較
バランス調整
開発時のデバッグ
```

の両方に使用できるようにする。

内部的には単なる射撃用モードに限定せず、

```text
Training Ground
Practice Range
```

のような汎用訓練モードとして設計する。

---

# 13. ボスシステム

Version 0.2.0から、実際にゲーム内へ登場するボスを追加する。

ボスは通常モンスターとは別枠。

既存仕様どおり、

```text
ゲーム開始から一定時間後に出現
出現地点を事前表示
出現までの残り時間を表示
```

する。

---

# 14. 仮ボス「ヘルブレイド」

```text
名称：ヘルブレイド

HP：700
攻撃力：26
移動速度：0.6

探知範囲：17

取得経験値：1000
取得コイン：800
```

---

# 15. ヘルブレイド出現時間

ヘルブレイドは、

```text
ゲーム開始3分後
```

に出現する。

出現地点：

```text
マップ内のランダムな位置
```

とする。

---

# 16. ボス出現予告

ヘルブレイド出現地点には、出現前からカウントダウンを表示する。

例：

```text
HELL BLADE
出現まで 30秒

↓

29
28
...

↓

0
↓

出現
```

---

# 17. ヘルブレイド通常攻撃

```text
攻撃力：26

射程：6
範囲：前方45°

予兆時間：1.2秒
攻撃CD：2.8秒
```

攻撃中は移動しない。

---

# 18. ヘルブレイド通常攻撃フロー

```text
攻撃対象決定
↓
攻撃範囲予兆表示
↓
1.2秒間静止
↓
攻撃判定発生
↓
攻撃CD 2.8秒開始
```

---

# 19. ヘルブレイドのアビリティ選択

戦闘開始後、

```text
最初の3回
```

は必ず通常攻撃を行う。

その後、通常攻撃の代わりにアビリティを使用する確率が発生する。

---

# 20. アビリティ使用確率

3回通常攻撃を行った後、

次の攻撃時：

```text
アビリティ使用率：30%
```

アビリティを使用せず通常攻撃を行った場合、

```text
次回アビリティ率 +30%
```

する。

例：

```text
4回目：30%

通常攻撃だった
↓

5回目：60%

通常攻撃だった
↓

6回目：90%

通常攻撃だった
↓

7回目：実質100%
```

アビリティを使用した場合、

```text
次回アビリティ率：30%
```

へリセットする。

射程：9
範囲：2.6

予兆時間：1.8秒

# 22. ヘルスラッシュ攻撃フロー

```text
攻撃対象決定
↓
攻撃範囲予兆
↓
1.8秒間静止
↓
38ダメージ
↓

```

# 23. 「攻撃間隔」の用語変更

今後、

```text
攻撃間隔
```

という表記を、

```text
攻撃CD
```

へ変更する。

---

# 24. 攻撃CDの定義

攻撃CDとは、

**その攻撃が発動した後、次の攻撃行動を開始できるまでの時間**

を意味する。

例：

```text
予兆1秒
↓
攻撃発動
↓
ここから攻撃CD3秒
↓
次の攻撃行動開始可能
```

---

# 25. 既存モンスターの攻撃間隔

過去の仕様で、

```text
攻撃間隔：○秒
```

と指定されていたものは、特別な指定がない限り、

```text
攻撃CD：○秒
```

としてそのまま読み替える。

---

# 26. ボス経験値

既存のボス共通仕様を維持する。

ヘルブレイドの総経験値：

```text
1000
```

この経験値を、

```text
80%：キルプレイヤー
20%：与ダメージ割合
```

で分配する。

---

# 27. ボスのコイン

ボスのコインは経験値とは異なり、

**分配しない。**

ヘルブレイド：

```text
800コイン
```

を、

```text
ボスをキルしたプレイヤー
```

へ全額付与する。

---

# 28. 近接モンスターの攻撃視認性

遠距離モンスターは投射物によって攻撃が比較的分かりやすい。

一方、近接モンスターは攻撃発生が分かりづらいため、

**攻撃範囲を視覚的に表示する。**

---

# 29. 近接攻撃の予兆

近接モンスターが攻撃を開始する場合、

```text
攻撃範囲を予兆表示
```

する。

表示例：

```text
前方扇形
短距離範囲
長方形
円形
```

等。

攻撃ごとの実際の当たり判定形状に合わせる。

---

# 30. 近接攻撃の視覚デザイン

予兆は、

```text
半透明
敵攻撃であることが分かる色
過度に画面を隠さない
```

デザインとする。

例：

```text
薄い赤
オレンジ
```

等。

---

# 31. 近接モンスターの攻撃猶予

通常の近接モンスターは、攻撃開始から即座にダメージを与えない。

```text
予兆時間：0.2秒
```

を基本とする。

---

# 32. 近接モンスター攻撃フロー

```text
敵を攻撃可能範囲に捉える
↓
攻撃予兆を表示
↓
0.2秒待機
↓
攻撃判定発生
↓
攻撃CD開始
```

---

# 33. 近接攻撃予兆と攻撃CD

予兆時間は攻撃CDに含めない。

例：

```text
予兆：0.2秒
攻撃CD：1秒
```

の場合、

```text
予兆0.2秒
↓
攻撃
↓
攻撃CD1秒
↓
次の攻撃予兆開始
```

となる。

---

# 34. 既存近接モンスターへの適用

特別な個別指定がない限り、

```text
雑魚近接
中モンスター近接
大モンスター近接
```

等の通常近接攻撃へ、

```text
0.2秒予兆
```

を追加する。

---

# 35. 特殊モンスターとの違い

魔女・ヘルブレイド等、すでに個別の予兆時間が指定されている攻撃については、

**個別指定値を優先する。**

例：

```text
通常近接
→ 0.2秒

魔女
→ 1秒

ヘルブレイド通常攻撃
→ 1.2秒

ヘルスラッシュ
→ 1.8秒
```
