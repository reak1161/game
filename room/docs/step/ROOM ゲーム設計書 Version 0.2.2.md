# 1. Version 0.2.2 更新概要

Version 0.2.2では、主に以下を追加・変更する。

- ボルテッカー系に残像演出を追加
- 射撃訓練場の管理画面をサイドパネル化

- メガボルテッカー時の画面揺れ・酔い対策を追加
- 高速移動終了後にカメラが自然に追いつく仕様を追加

# 2. ボルテッカー系の残像

以下のダッシュ系アビリティに残像演出を追加する。

```text
ボルテッカー
メガボルテッカー
```

高速移動中、アウトローの薄い残像を短時間表示する。

目的：

```text
移動方向を分かりやすくする
高速移動感を強調する
攻撃軌道を認識しやすくする
```

---

# 3. メガボルテッカーの残像

メガボルテッカーでは、残像によって特に、

**稲妻状のジグザグ軌道**

が視覚的に分かるようにする。

残像は実際に通過した軌道へ短時間残す。

ただし、

```text
残像自体には攻撃判定なし
```

とする。

純粋な視覚演出として扱う。

---

# 4. 射撃訓練場 管理画面変更

射撃訓練場の管理画面は、

**画面中央へ表示するモーダルUIを基本としない。**

代わりに、

**画面端へ表示するサイドパネル形式**

とする。

---

# 5. 管理画面表示中の操作

管理画面を開いている間も、アウトローを通常通り操作できる。

例：

```text
WASD移動
通常攻撃
Q / Eスキル
ダッシュ
アビリティ挙動確認
```

等。

設定画面を閉じることなく、その場で変更内容を試せるようにする。

---

# 6. 訓練場での基本フロー

```text
管理画面を開く
↓
レベルやアビリティを変更
↓
そのまま移動・攻撃
↓
デコイへ攻撃
↓
ダメージ / DPS確認
↓
再び設定変更
```

という短いサイクルで検証できることを重視する。

---

# 7. 管理パネルの表示

サイドパネルは必要に応じて、

```text
開く
閉じる
折りたたむ
```

ことができる構造を想定する。

戦闘画面を完全に覆わないことを優先する。

---

# 8. カメラ追従の基本方針

通常移動時は、従来通りアウトローを中心としてカメラを追従させる。

ただし、高速移動時にプレイヤー位置へ完全追従すると、

```text
急激な画面移動
細かな左右振動
酔いやすさ
```

につながるため、追従方式を変更する。

---

# 9. 高速移動時のカメラ

以下のような高速移動中は、

```text
ダッシュ
ボルテッカー
メガボルテッカー
紫電一閃
タイムスリップ
その他高速移動
```

カメラをプレイヤーへ即時追従させない。

代わりに、

**緩やかにプレイヤー位置へ追従する。**

---

# 10. メガボルテッカーとカメラ

メガボルテッカーは、

```text
左
↓
右
↓
前方
```

と短時間でジグザグ移動する。

カメラがこれを完全追従すると画面そのものも激しく左右へ動いてしまう。

そのため、

**細かなジグザグ軌道へカメラがそのまま追従しない。**

全体的な進行方向を中心に、滑らかにカメラを移動させる。

---

# 11. カメラ遅延

高速移動時はカメラが少し遅れてプレイヤーを追う。

ただし、

**遅れすぎないこと**

も重要とする。

プレイヤーが画面端付近まで移動して操作しづらくならないよう、

```text
最大カメラ遅延距離
```

を設定可能な構造とする。

具体値はプレイテストで調整する。

---

# 12. 高速移動終了後

高速移動が終了した場合、

カメラはプレイヤーの現在位置へ、

**短時間で自然に追いつく。**

瞬間移動のようにカメラを飛ばさず、

```text
高速移動中
→ 少し遅れて追従

高速移動終了
→ 追従速度を戻す
→ プレイヤー位置へ自然に収束
```

という流れにする。

---

# 13. カメラ補間

実装上は、カメラ位置をプレイヤー位置へ毎フレーム直接設定せず、

**補間処理**

を使用することを推奨する。

概念：

```text
cameraPosition
+=
(targetPosition - cameraPosition)
× followStrength
```

通常時と高速移動時で、

```text
followStrength
```

を変更できるようにする。

---

# 14. 進行方向の先読み

必要に応じて、

**プレイヤーの移動方向側を少し広く表示するカメラ先読み**

も追加可能とする。

つまり、アウトローを常に完全な画面中央へ置くのではなく、

```text
進行方向
→ 少し広めに表示
```

する。

これにより、高速移動後の進行方向を確認しやすくする。
