# 1. Version 0.1.17 更新概要

Version 0.1.17では、主に以下を追加・変更する。

- 新アビリティ「ぱちぱちスパーク」を追加
- スリップダメージの共通仕様を設定
- スケーター「冷気纏い」を共通スリップダメージ仕様へ統合
- 「いてつく冷気」を強化
- 「マリンベール」の視覚表現を強化
- プラウラー「フェロモン」を強化
- 「バブルランチャー」の泡サイズを変更
- 既存アウトローの初期HP・攻撃を全体調整
- レベルアップによる基礎ステータス成長を追加
- 最大HP上昇時の回復仕様を追加
- ゼウス「エネルギーチャージ」の回復を割合回復へ変更
- 新アウトロー「フューチャー」を追加

# 2. アビリティ「ぱちぱちスパーク」

自身の周辺に「電気の粒」を継続的に生成するアビリティ。

```text
名称：ぱちぱちスパーク
```

電気の粒は、自身を中心として、

```text
半径4～7
```

の範囲内からランダムな位置に生成される。

---

# 3. 電気の粒

```text
サイズ：0.5
生成間隔：3～5秒ごとに1個
滞留時間：10秒
```

生成位置は毎回ランダム。

---

# 4. 電気の粒を自分が取得した場合

自身が電気の粒へ接触すると、その粒を取得する。

1個取得するごとに、

```text
移動速度 +5%
```

を得る。

効果時間：

```text
10秒
```

最大ストック：

```text
5
```

したがって最大：

```text
移動速度 +25%
```

---

# 5. ぱちぱちスパークの効果時間更新

新しい電気の粒を取得するたび、

**現在所持しているストック全体の残り時間を10秒へ更新する。**

例：

```text
3ストック
移動速度+15%
残り2秒

↓ 電気の粒を取得

4ストック
移動速度+20%
残り10秒
```

---

# 6. 敵が電気の粒へ接触した場合

敵が電気の粒へ接触している間、

```text
1スリップダメージ
```

を与える。

スリップダメージの発生間隔は共通仕様を使用する。

---

# 7. スリップダメージ共通仕様

今後、

```text
スリップダメージ
```

と表記されたダメージは、原則として以下の共通仕様を使用する。

```text
発生間隔：0.5秒ごと
防御系効果を無視
```

つまり、

- 被ダメージ軽減
- その他の防御系バフ

による軽減を受けない。

各スキル・アビリティ側では、1回あたりのダメージ量のみ個別指定できる。

---

# 8. スケーター「冷気纏い」

既存の「冷気纏い」のダメージは、

**スリップダメージ**

として明確に扱う。

```text
0.5秒ごとに1スリップダメージ
```

したがって、防御系効果を無視する。

その他の既存仕様：

```text
冷気サイズ：0.7
持続：7秒
```

は維持する。

# 10. マリンベールの視覚表現

水属性アビリティ「マリンベール」は、現在使用可能かどうかを戦闘中に視覚的に把握できるようにする。

使用可能時：

```text
プレイヤー周囲に泡 / 水膜等の表現を表示
```

軽減効果発動後：

```text
水膜等の表現を消す
```

CD回復後：

```text
再び水膜等を表示
```

効果そのものは既存仕様を維持する。

```text
最初に受ける1回のダメージを60%軽減
発動後CD10秒
```

---

# 11. プラウラー「フェロモン」強化

既存仕様：

```text
CD：11秒
範囲：自身中心 半径20
持続：10秒
```

対象：

```text
範囲内の敵モンスター
```

効果を以下へ変更する。

```text
探知範囲を20にする
移動速度 +25%
```

これによりモンスターを広範囲から引き寄せ、さらに高速で接近させる。

---

# 12. バブルランチャー調整

バブルランチャーの泡サイズを、

```text
0.4
```

へ変更する。

既存仕様：

- 5個生成
- ランダム方向
- 移動速度0.4～1.2/s
- 移動距離0.5～1.8
- 移動後最大5秒滞留
- 命中時 💧6
- 命中した泡は消滅
- 貫通なし

は維持する。

# 18. 最大HP上昇時の現在HP

レベルアップによって最大HPが増加した場合、

**増加した最大HPと同じ量だけ現在HPも回復する。**

例：

```text
最大HP：250
現在HP：130

↓ レベルアップ

最大HP：255
増加量：+5

↓

現在HP：135
```

最大HPだけが増えて現在HPの割合が低下する挙動にはしない。

# 26. E「ロールバック」

```text
名称：ロールバック
CD：24秒
```

発動すると、

```text
3秒前の位置
```

へ、

```text
0.3秒
```

かけて戻る。

---

# 27. ロールバックとHP

位置だけでなく、

**現在HPを3秒前の状態へ戻す。**

ただし、

- レベル
- 最大HP
- その他恒久的な成長

そのものは巻き戻さない。

3秒間にレベルアップ等によって最大HPが変化していた場合も、

**現在の最大HPを使用する。**

つまり巻き戻すのは現在HPであり、最大HPではない。

---

# 28. E「タイムボム」

```text
名称：タイムボム
CD：8秒
最大射程：5
範囲：半径0.5
```

マウス位置を指定地点として使用する。

最大5までであれば、

**手前の位置にも任意に指定可能。**

---

# 29. タイムボムの発動

指定地点へボムを発射し、

```text
0.3秒後
```

に攻撃判定を発生させる。

命中した敵へ3秒間、

```text
移動速度 -70%
CD回復速度 -50%
```

を付与する。

---

# 30. E「タイムスリップ」

```text
名称：タイムスリップ

CD：4秒 / 1スタック
最大スタック：3
```

発動すると、

```text
前方3
```

へ、

```text
0.1秒
```

かけて移動する。

1回の使用につき1スタックを消費する。

---

# 31. タイムスリップのチャージ

最大3スタックを保持可能。

チャージ回復は、既存の複数チャージ系と同様に、

**各チャージを独立して回復する方式**

を基本とする。
