# 2. アビリティ「メガボルテッカー」

```text
名称：メガボルテッカー
条件：ボルテッカー
```

ボルテッカーをさらに強化・置換するダッシュ系アビリティ。

通常の直線移動ではなく、

**稲妻のようなジグザグ軌道**

で高速移動する。

---

# 3. メガボルテッカーの移動軌道

発動地点と発動時の正面方向を基準に、複数区間を連続移動する。

概念的な軌道：

```text
始点
↓
左側へ折れる
↓
右側へ横切る
↓
正面奥の終点へ移動
```

より具体的には、

```text
第1地点：
前方2.5を基準に左30°方向
始点からの移動距離：約2.88

第2地点：
第1地点から横方向へ約2.88移動
始点基準の右30°側へ移動

最終地点：
始点から正面前方5
```

とする。

この3区間を連続して移動することで、稲妻状の軌道を描く。

---

# 4. メガボルテッカーの移動時間

軌道全体を、

```text
0.3秒
```

で移動する。

---

# 5. メガボルテッカーの攻撃

移動軌道上で敵に命中した場合、

```text
⚡14ダメージ
```

を与える。

既存のボルテッカー：

```text
前方4
0.2秒
⚡10
CD7秒
```

から、

- 移動軌道
- 最終到達位置
- 移動時間
- ダメージ

を変更する。

---

# 6. メガボルテッカーの継承要素

個別指定されていない仕様は、ボルテッカーから引き継ぐ。

現時点では、

```text
発動キー：Space
CD：7秒
ダッシュ系チャージ数
```

等を継承する。

そのため「ダブルダッシュ」取得時は、メガボルテッカーも同様に複数チャージを持てる。

# 9. アビリティ「目にもとまらぬ」

```text
名称：目にもとまらぬ
条件：ダッシュ
```

ダッシュ系アクションを発動した際、

```text
0.5秒間無敵
```

を得る。

---

# 10. 「目にもとまらぬ」とダッシュ派生

「目にもとまらぬ」の条件である、

```text
ダッシュ
```

は、現在のアビリティが完全に初期ダッシュそのものであることを要求しない。

ダッシュから派生したアビリティも条件を満たす。

例：

```text
ダッシュ
→ 条件成立

ボルテッカー
→ 条件成立

メガボルテッカー
→ 条件成立
```

したがって、ボルテッカー・メガボルテッカー発動時も、

```text
0.5秒間無敵
```

を得る。

---

# 11. アビリティ前提条件の継承ルール

アビリティの前提条件は、

**現在装備している名称だけではなく、そのアビリティの派生元・前提系統まで含めて判定する。**

例：

```text
ダッシュ
↓
ボルテッカー
↓
メガボルテッカー
```

の場合、

メガボルテッカーは、

```text
ボルテッカー条件
ダッシュ条件
```

の両方を満たす。

---

# 12. 前提条件判定の考え方

前提アビリティが上位アビリティによって置換された場合でも、

**元の前提条件を失わない。**

つまり、

```text
「ダッシュが必要」
```

という条件は、

「現在のSpaceアビリティがダッシュという名前である」

という意味ではない。

正しくは、

```text
ダッシュ系統を取得済みである
```

という意味で扱う。

---

# 13. 実装上の推奨

前提条件判定を単純な名称比較だけで実装しない。

概念例：

```text
abilityLineage
abilityTags
prerequisiteChain
```

等を利用し、

```text
メガボルテッカー
→ ボルテッカー系統
→ ダッシュ系統
```

という派生関係を追跡できる構造にする。
