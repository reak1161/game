# 1. Version 0.1.18 更新概要

Version 0.1.18では、主に以下を追加・変更する。

- フューチャー「ロールバック」の移動方式を変更
- ロールバック中に無敵を追加
- Lv1～25のHP成長曲線を暫定設定
- Lv1～25の攻撃成長曲線を暫定設定
- ボスモンスターの基本出現システムを追加
- ボス経験値の分配方式を追加
- フューチャーのパッシブ「時空管理」を確定
- アウトローの遠距離通常攻撃のデフォルト弾速を変更

---

# 2. フューチャー「ロールバック」変更

```text
名称：ロールバック
CD：24秒
```

発動すると、3秒前の自分の位置へ、

```text
0.3秒
```

かけて戻る。

ただし、現在位置から3秒前の地点へ単純な直線移動は行わない。

---

# 3. ロールバックの移動軌道

ロールバックでは、

**過去3秒間に自分が実際に移動した経路を、ある程度逆向きになぞって戻る。**

概念：

```text
過去の移動

A
↓
B
↓
C
↓
現在位置 D
```

ロールバック：

```text
D
↓
C
↓
B
↓
A
```

のように移動する。

---

# 4. 過去位置の記録

完全なフレーム単位の移動履歴を再現する必要はない。

一定間隔で、

```text
位置履歴
```

を保存しておき、それらを補間しながら逆順に移動する。

目的は、

**「3秒前まで自分の時間を巻き戻している」ような軌道を視覚的に表現すること**

とする。

---

# 5. ロールバック中の無敵

ロールバックによる移動中は、

```text
無敵
```

とする。

つまり約0.3秒間、

敵からのダメージを受けない。

---

# 6. ロールバックとHP

既存仕様通り、移動完了時に、

**現在HPを3秒前の現在HPへ戻す。**

ただし以下は巻き戻さない。

```text
レベル
最大HP
取得アビリティ
恒久的なステータス成長
その他ゲーム進行
```

3秒間にレベルアップ等で最大HPが変化していた場合も、

**現在の最大HPは維持する。**

---

# 7. レベルアップによるHP成長

アウトローのLv1基礎HPを、

```text
H0
```

現在レベルを、

```text
L
```

とした場合、暫定的に以下の成長式を使用する。

```text
HP(L)
=
floor(
    H0 ×
    [1 + 0.01(L - 1) + 0.0015(L - 1)^2]
)
```

小数点以下は切り捨てる。

# 9. 最大HP上昇時の回復

既存仕様通り、レベルアップで最大HPが増加した場合、

**最大HP増加量と同じだけ現在HPも回復する。**

例：

```text
最大HP：290 → 300
現在HP：150

最大HP増加量：+10

↓

最大HP：300
現在HP：160
```

# 11. Lv12以降の攻撃成長

Lv12以降は、基準攻撃値を以下で求める。

```text
Aref(L)
=
floor(
    28
    + 4(L - 11)
    + 0.3(L - 11)^2
)
```

# 13. アウトローごとの攻撃成長

各アウトローのLv1攻撃値を、

```text
A0
```

とした場合、Lvごとの攻撃は、

```text
Attack(L)
=
floor(
    A0 × Aref(L) / 9
)
```

で求める。

これにより、各アウトローの初期攻撃力差を維持しながら成長できる。

---

# 14. 成長曲線の扱い

HP・攻撃の成長曲線は、

**現時点では暫定値**

とする。

実際のプレイテスト結果に応じて、

```text
HP成長率
攻撃成長率
二次係数
後半の伸び
```

等を調整可能にする。

計算式や係数をハードコードせず、設定値として管理することを推奨する。

---

# 15. ボスモンスター

実際のゲームでは、通常モンスターとは別に、

```text
ボス
```

が存在する。

ボスは試合開始直後からランダムスポーンするのではなく、

**ゲーム開始から一定時間後に出現する。**

具体的な出現時間はボスごとに設定可能とする。

---

# 16. ボス出現地点

ボスは出現前から、

**出現予定地点がマップ上に存在する。**

その場所には、

```text
ボス出現までの残り時間
```

を表示する。

例：

```text
BOSS
出現まで 30秒

↓

29秒
28秒
27秒
...

↓

0秒

↓

ボス出現
```

---

# 17. ボス出現予告の目的

プレイヤーは事前にボス出現地点を確認できるため、

```text
ボスを狙いに行く
ボスを避ける
先に周囲を確保する
他アウトローとの戦闘を仕掛ける
```

等の判断が可能になる。

---

# 18. ボス経験値

ボスは通常モンスターとは異なる経験値分配方式を使用する。

ボスが持つ総経験値を、

```text
撃破報酬：80%
ダメージ貢献報酬：20%
```

に分ける。

---

# 19. ボス撃破報酬

ボスへ最後の一撃を与え、撃破したプレイヤーは、

```text
ボス総経験値の80%
```

を獲得する。

---

# 20. ダメージ貢献報酬

残りの、

```text
20%
```

は、各アウトローがボスへ与えたダメージ量に応じて比例分配する。

例：

```text
ボス総経験値：1000

A：500ダメージ
B：300ダメージ
C：200ダメージ

Bがボスを撃破
```

ダメージ貢献分：

```text
1000 × 20%
= 200XP
```

分配：

```text
A：100XP
B：60XP
C：40XP
```

撃破報酬：

```text
B：800XP
```

最終結果：

```text
A：100XP
B：860XP
C：40XP
```

撃破したプレイヤーも、自身のダメージ量に応じた20%側の分配対象になる。

---

# 21. フューチャー パッシブ「時空管理」

未定だったフューチャーのパッシブを確定する。

```text
名称：時空管理
```

---

# 22. 時空管理：自身のCD

自分のスキルが1つ以上CD中の場合、

```text
ダメージ +5%
```

を得る。

---

# 23. 時空管理：攻撃対象のCD

現在攻撃している対象のスキルが1つ以上CD中の場合、

```text
さらにダメージ +10%
```

を得る。

---

# 24. 時空管理の組み合わせ

```text
自分だけCD中
→ ダメージ+5%

対象だけCD中
→ ダメージ+10%

自分と対象の両方がCD中
→ ダメージ+15%

どちらもCD中ではない
→ 補正なし
```

現時点では主に、

```text
Q / E等のスキルCD
```

を対象とする。

ダッシュやアイテム等をCD判定に含めるかは必要に応じて別途定義する。

---

# 25. アウトロー遠距離通常攻撃の弾速変更

アウトローの遠距離通常攻撃について、

旧デフォルト：

```text
2/s
```

を廃止する。

新デフォルト：

```text
8/s
```

とする。

---

# 26. 投射物デフォルトとの区別

以下は別のデフォルト値として管理する。

```text
アウトロー遠距離通常攻撃
→ 8/s

一般的な投射物
→ 5/s
```

スキル・アビリティ・モンスター等で個別の弾速が指定されている場合は、

**個別指定値を優先する。**
