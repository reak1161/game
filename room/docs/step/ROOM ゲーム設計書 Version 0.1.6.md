# 2. プレイヤー遠距離通常攻撃

既存の遠距離通常攻撃にデフォルト弾速を追加する。

```text
攻撃タイプ：遠距離
攻撃間隔：1秒
射程：前方2.9
弾サイズ：0.2
弾速：2/s
ダメージ：キャラクターの基礎攻撃力
```

キャラクターまたは能力による個別指定がない場合、遠距離通常攻撃の弾速は `2/s` を使用する。

メロディアについても、通常状態ではこの共通仕様を適用する。

# 3. ゼウス パッシブ名称変更

ゼウスのパッシブ名称を以下に確定する。

```text
「電光石火」
```

## 効果

移動速度が上昇するほど、スキルのクールダウン回復速度が上昇する。

基準移動速度は `1.0`。

移動速度 `2.0` の場合、

```text
クールダウン回復速度 +50%
```

とする。

既存の効果内容に変更はない。

# 5. キャラクター「スケーター」

## 5.1 基礎ステータス

```text
名前：スケーター

HP：250
攻撃タイプ：近接
攻撃力：11
移動速度：1.2
```

氷属性を中心とした、移動・エリア制圧・凍結を特徴とする近接キャラクター。

---

# 6. スケーター パッシブ「冷気纏い」

```text
名称：冷気纏い
```

## 概要

自分は冷気をまとう。

## 効果

スケーターが移動した経路に「冷気」を滞留させる。

```text
冷気サイズ：0.7
持続時間：7秒
```

「冷気」にスケーター以外の対象が接触している場合、

```text
0.5秒ごとに1スリップダメージ
```

を与える。

スケーター自身は、自分の「冷気」によるダメージを受けない。

# 12. 共通状態「凍結蓄積」

「凍結」は蓄積型の状態異常として扱う。

対象は凍結蓄積値を持つ。

例：

```text
0%
↓
35%
↓
70%
↓
100%
```

凍結蓄積値が `100%` に到達した場合、対象は「凍結状態」になる。

蓄積値の自然減少、持続時間、100%超過時の処理等はTBD。

---

# 13. 共通状態「凍結」

凍結蓄積が100%になると発生する。

## 効果

```text
最大持続時間：3秒
移動：不可
```

凍結中は移動できない。

---

# 14. 凍結解除条件

凍結は以下のどちらかを満たした時点で解除する。

```text
・凍結開始から3秒経過
・ダメージを1回受ける
```

---

# 15. 凍結中の被ダメージ

凍結中に最初に受ける1回の攻撃について、

```text
被ダメージ +20%
```

とする。

そのダメージ処理後、凍結状態を解除する。

概念：

```text
凍結状態
↓
攻撃を受ける
↓
その1撃のみダメージ ×1.2
↓
氷が割れる
↓
凍結解除
```

多段攻撃の場合でも、凍結による+20%補正を受けるのは最初の1ヒットのみ。

その後のヒットは通常ダメージとして処理する。

---

# 16. 凍結の演出方針

凍結中にダメージを受けて解除された場合、

**凍っていた氷が攻撃によって割れる**

ことが視覚的に分かる演出を想定する。

具体的なエフェクトはTBD。

# 17. スケーターの基本的な特徴

スケーターは、

```text
移動
↓
冷気を残す
↓
敵の行動範囲を制限
↓
凍結を蓄積
↓
敵を凍結
↓
強い1撃で氷を割る
```

という戦闘の流れを持つことを想定する。

ただし、特定のコンボを強制するものではない。
