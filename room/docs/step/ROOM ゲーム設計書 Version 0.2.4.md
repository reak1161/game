# 2. スタック制CD

スタック制スキル・アビリティのCDは、

**各スタックが独立して同時回復する方式ではない。**

1つずつ順番に回復する。

例：

```text
最大3スタック
1スタックCD：4秒

3 → 2
2 → 1
1 → 0

4秒後
→ 1/3

さらに4秒後
→ 2/3

さらに4秒後
→ 3/3
```

複数の回復タイマーを同時進行させない。

---

# 3. 既存スタック制能力への適用

以下を含む既存のスタック制能力も、この共通仕様へ統一する。

```text
ダブルダッシュ
タイムスリップ
その他の複数チャージ能力
```

過去仕様にあった「各チャージ独立回復」は廃止する。

---

# 4. スキルアイコンのCD表示

スキル・アビリティのCDは、アイコン内の数値だけでなく、

**アイコン外周の枠**

でも進行状況が分かるようにする。

---

# 5. CDフレーム

例：

```text
使用直後
→ 枠が空になる

CD進行
→ 外周が時計回り等で徐々に埋まる

CD完了
→ 枠が一周
→ 使用可能状態を視覚的に強調
```

通常戦闘中でも一目でCD状況を把握できることを優先する。

---

# 6. スタック制能力のCD表示

スタック制能力では、

**次の1スタックが回復するまでのCD**

を外周表示する。

例：

```text
現在：0 / 3
CD：4秒

4秒かけて外周が一周
↓
1 / 3
↓
外周をリセット
↓
次の4秒を表示
```

現在スタック数は、

```text
1 / 3
2 / 3
3 / 3
```

等でアイコン上に併記する。

---

# 7. ボスのマッピング

ボスもマッピング対象とする。

対象：

```text
ボス出現予定地点
出現後のボス位置
```

取得したボス関連情報はマップへ表示可能とする。

リアルタイム追跡か最終確認位置表示か等の細かな更新条件は、必要に応じて別途定義する。

# 13. 敵の弱点・耐性

敵には、まれに、

```text
弱点
耐性
```

が設定される。

現時点の既存モンスターは、

```text
全員：無属性
```

とする。

---

# 14. 弱点補正

弱点となる攻撃を受けた場合、

```text
ダメージ ×2
```

とする。

---

# 15. 耐性補正

耐性を持つ攻撃を受けた場合、

```text
ダメージ ×0.5
```

とする。

---

# 16. 弱点特攻との組み合わせ

弱点特攻取得中に弱点を突いた場合、

```text
弱点補正 ×2
+
弱点特攻 ×1.5
```

を乗算する。

最終的に、

```text
基礎ダメージ ×3
```

となる。

# 17. アビリティ「凍える風」

```text
名称：凍える風
```

自身を中心として、周囲の敵へ継続的に凍結蓄積を与える。

---

# 18. 凍える風の範囲

半径5以内の敵：

```text
毎秒 凍結蓄積 +5%
```

さらに、半径2以内の敵プレイヤー：

```text
追加で毎秒 凍結蓄積 +5%
```

そのため敵プレイヤーの場合、

```text
半径2以内
→ 毎秒 +10%

半径2～5
→ 毎秒 +5%
```

となる。

---

# 19. アビリティ「凍結ブレイカー」

```text
名称：凍結ブレイカー
条件：凍結系能力
```

条件例：

```text
いてつく冷気
その他凍結蓄積を扱う能力
```

---

# 20. 凍結ブレイカーの効果

凍結状態の敵へ、

```text
ダメージ +50%
```

を与える。

既存の凍結状態では最初に受けるダメージが、

```text
120%
```

になる。

凍結ブレイカー取得中なら、

```text
1.2 × 1.5
= 1.8
```

となり、

**最初の一撃は基礎ダメージの180%**

となる。

その後、既存仕様通り凍結状態は解除される。

# 23. アビリティ「潮が満ちる」

```text
名称：潮が満ちる
```

被ダメージ軽減を徐々に蓄積するアビリティ。

---

# 24. 潮が満ちる：蓄積フェーズ

毎秒、

```text
1スタック
```

獲得する。

1スタックにつき、

```text
被ダメージ軽減 +1%
```

を得る。

最大：

```text
10スタック
```

---

# 25. 10スタック未満で被弾した場合

10スタックへ到達する前にダメージを受けた場合、

```text
現在の全スタック消滅
```

とする。

その後、再び毎秒1スタックずつ蓄積する。

---

# 26. 10スタック到達時

10スタックまで蓄積すると、

```text
被ダメージ軽減 +40%
```

へ変換される。

以降は通常の蓄積フェーズとは異なる状態になる。

---

# 27. 強化後の被弾

被ダメージ軽減+40%状態では、ダメージを受けるたび、

```text
スタック -1
```

する。

ただし、

```text
残り9スタック
残り5スタック
残り1スタック
```

などになっても、

**被ダメージ軽減+40%は維持する。**

---

# 28. 強化状態の終了

スタックが、

```text
0
```

になると、

```text
被ダメージ軽減+40%
```

が終了する。

---

# 29. 強化状態中の蓄積

10スタック到達後、スタックが被弾によって減少している間は、

**新しいスタックを獲得しない。**

0スタックになって強化状態が解除された後、

再び、

```text
毎秒1スタック
```

の蓄積フェーズへ戻る。

---

# 30. 新アウトロー「ポセイドン」

```text
名称：ポセイドン

HP：270
タイプ：遠距離
攻撃：4.5
移動速度：0.8
```

水属性を中心に、高速移動・引き寄せ・反射等を扱うアウトロー。

---

# 31. ポセイドン通常攻撃

```text
射程：3.4
攻撃CD：2秒
```

攻撃時、

```text
正面
左18°
右18°
```

の3方向へ同時発射する。

弾速は個別指定がないため、

```text
アウトロー遠距離通常攻撃デフォルト：8/s
```

を使用する。

---

```text

```

---

# 36. ジェットサーファーの操作感

発動中は前後方向への高速移動を重視する。

左右への慣性・操作反応を弱くし、

**左右へ移動・旋回しにくい**

操作感とする。

水流・水しぶき等の専用エフェクトを付与する。

---

# 37. ジェットサーファーのカメラ

高速移動能力のため、

既存の高速移動用カメラ仕様を適用する。

```text
カメラをプレイヤーへ即時固定しない
少し遅れて追従
高速移動終了後に自然に追いつく
```
