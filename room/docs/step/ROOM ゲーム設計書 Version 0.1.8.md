# 1. Version 0.1.8 更新概要

Version 0.1.8では、主に以下を追加・変更する。

- ゲーム内用語を「アウトロー」「モンスター」へ統一
- ゲーム中に確認できるモンスター一覧機能を追加
- モンスター一覧にHP・取得経験値幅等を表示
- 中モンスターの取得経験値を追加
- テスト環境のモンスタースポーン数を時間経過で増加させる仕様を追加

---

# 2. 用語統一

ゲーム内および設計書内では、以下の名称を基本用語として使用する。

```text
プレイヤーキャラクター
→ アウトロー

Mob
→ モンスター

雑魚Mob
→ 雑魚モンスター

中Mob
→ 中モンスター

強Mob
→ 強モンスター
```

可能な限り新規記述では `Mob` という表現を使用せず、`モンスター` に統一する。

タイトル、

```text
Royale Of Outlaws & Monsters
```

の `Outlaws` / `Monsters` とゲーム内用語を一致させる。

---

# 3. アウトロー

プレイヤーが操作するキャラクターを、

```text
アウトロー
```

と呼ぶ。

例：

- ゼウス
- メロディア
- スケーター

今後追加されるプレイヤーキャラクターについても、ゲーム内分類はアウトローとする。

---

# 4. モンスター

PvE要素としてマップ上に出現する敵を、

```text
モンスター
```

と呼ぶ。

現時点の基本分類：

```text
雑魚モンスター
中モンスター
強モンスター
```

将来的には、

- エリートモンスター
- ボスモンスター
- 特殊モンスター

等を追加可能。

# 7. モンスター一覧のデータ管理

モンスター一覧専用の数値を別途記述するのではなく、実際のゲームで使用するモンスターデータを参照して表示する。

概念：

```ts
interface MonsterDefinition {
  id: string;
  name: string;

  category: MonsterCategory;

  hp: number;
  moveSpeed: number;

  attackType: AttackType;
  attackRange: number;
  attackDamage: number;
  attackInterval: number;

  expMin: number;
  expMax: number;

  spawnConditions: SpawnCondition[];
}
```

具体的な型定義は実装時に変更可能。

この方針により、

```text
ゲーム上のHP
≠
一覧画面のHP
```

のようなデータ不整合を防止する。

# 9. 雑魚モンスター

既存仕様を継続する。

取得経験値：

```text
3～5
```

近接・遠距離ともに、テスト段階では同じ取得経験値幅を使用する。

---

# 10. 中モンスター

テスト段階の中モンスターの取得経験値を以下に設定する。

```text
7～12
```

近接・遠距離ともに同じ取得経験値幅を使用する。

---

# 11. 中モンスター 共通仕様

```text

取得経験値：7～12
```

ゲーム開始から1分経過後、雑魚モンスターの代わりとして一定確率で出現する。

# 14. テスト環境のモンスタースポーン

スポーン間隔は既存仕様を継続する。

```text
7～10秒ごと
```

スポーンごとに次の出現までの時間をランダムに決定する。

---

# 15. スポーン数の時間経過増加

テスト環境では、1回のスポーンで出現するモンスター数を時間経過とともに増加させる。

ゲーム開始直後：

```text
2～5体
```

1分経過時点：

```text
4～6体程度
```

その後も時間経過に応じて徐々に増加させる。

---

# 16. 暫定スポーン数テーブル

初期テスト用として、以下を暫定値とする。

| 経過時間 | 1回のスポーン数 |
|---|---:|
| 0:00～0:59 | 2～5体 |
| 1:00～1:59 | 4～6体 |
| 2:00～2:59 | 5～7体 |
| 3:00～4:59 | 6～8体 |
| 5:00以降 | 7～10体 |

このテーブルはテスト用であり、実際のプレイ密度に応じて変更する可能性が高い。

---

# 17. 中モンスター出現判定

ゲーム開始から1分経過後、スポーンする各モンスターについて個別に判定する。

```text
80%：雑魚モンスター
20%：中モンスター
```

中モンスターになった場合は、

```text
近接
または
遠距離
```

をランダムで決定する。

---

# 18. スポーン例

ゲーム開始2分経過後に、スポーン数が6体だった場合：

```text
Monster 1 → 雑魚
Monster 2 → 雑魚
Monster 3 → 中
Monster 4 → 雑魚
Monster 5 → 中
Monster 6 → 雑魚
```

のように、各個体で独立して20%判定を行う。

1回のスポーン全体を中モンスターウェーブへ置き換える仕様ではない。

---

# 19. スポーンシステムの拡張方針

現在のスポーン仕様はプロトタイプ・テスト用。

将来的には以下を考慮して調整可能にする。

```text
経過時間
プレイヤー人数
現在のモンスター数
マップエリア
バイオーム
アウトローの平均レベル
ゲーム進行状況
```

また、必要に応じてモンスターの同時存在数上限を設定する。
