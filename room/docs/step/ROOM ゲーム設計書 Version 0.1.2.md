# 2. 能力説明文の記述ルール

スキル、アビリティ、パッシブ等の説明文は、可能な限り共通した形式で記載する。

## 2.1 概要文

能力名の直後に、その能力の大まかな内容を示す短い説明文を記載する場合がある。

例：

```text
「フレイムダンス」
自分の周りを炎が回る。
```

この1文は能力の概要を直感的に伝えるためのものであり、詳細な数値仕様とは分離して扱う。

# 3. 属性ダメージ表記

属性を持つダメージは、原則として属性アイコンを付けて表記する。

例：

```text
🔥10ダメージ
💧6ダメージ
⚡10ダメージ
❄12ダメージ
```

現時点で使用する主な属性アイコン：

| 属性 | 表記 |
|---|---|
| 炎 | 🔥 |
| 水 | 💧 |
| 雷 | ⚡ |
| 氷 | ❄ |

光・闇のアイコンはTBD。

属性を持たないダメージについては、属性アイコンを付けない。

# 4. 距離・範囲・サイズの基準

ゲーム内で使用する、

- 距離
- 半径
- 幅
- 射程
- サイズ

等の数値は、プレイヤーキャラクターのデフォルト当たり判定サイズを基準とした相対単位として扱う。

プレイヤーの基準サイズ：

```text
1.0
```

例：

```text
前方2.5
半径1.5
幅1.0
サイズ0.7
射程5
```

---

# 5. 距離関連の用語

## 5.1 前方X

キャラクターを起点とし、指定方向へXの位置または範囲を示す。

例：

```text
前方4
```

---

## 5.2 射程X

弾・攻撃・オブジェクト等が到達できる最大距離を示す。

例：

```text
射程5
```

---

## 5.3 半径X

円形範囲の半径。

例：

```text
半径1.5
```

---

## 5.4 幅X

直線攻撃や矩形範囲の横幅。

例：

```text
前方4、幅1
```

---

## 5.5 サイズX

弾、炎、つらら、Mob等の個別オブジェクトの当たり判定サイズ。

例：

```text
サイズ0.7
```

---

# 6. 移動時間と移動速度の表記

すべての移動処理を速度表記だけに統一することはしない。

能力の性質によって以下を使い分ける。

## 6.1 距離＋所要時間

ダッシュや突進など、

**「どこまで移動するか」と「何秒で到達するか」が重要な能力**

では、距離と所要時間を記載する。

例：

```text
前方4へ0.5秒かけて移動する。
```

内部的な移動速度は実装側で算出してよい。

---

## 6.2 速度

弾や漂うオブジェクトなど、

**移動速度そのものが能力の特徴となるもの**

は速度で記載する。

例：

```text
速度0.4～1.2/s
```

---

# 7. プレイヤー通常攻撃

プレイヤーの通常攻撃は自動発動する。

通常攻撃タイプはキャラクターごとに保持する。

現時点では、

- 近接
- 遠距離

の2種類を使用する。

通常攻撃のダメージ量は各キャラクターの基礎攻撃力を使用する。

---

# 8. プレイヤー近接攻撃

```text
タイプ：近接
射程：1
攻撃間隔：0.8秒
```

射程内に有効な攻撃対象が存在する場合、自動的に攻撃する。

---

# 9. プレイヤー遠距離攻撃

```text
タイプ：遠距離
射程：2
攻撃間隔：1秒
```

射程内に有効な攻撃対象が存在する場合、自動的に攻撃する。

遠距離攻撃は弾を射出する形式を想定する。

弾速等はTBD。

# 11. 初期Mob仕様

初期プロトタイプでは、Mobを以下の2種類に限定する。

```text
近接Mob
遠距離Mob
```

スポーン時にランダムで種類を決定する。

両者はゲーム上で判別できるよう、見た目を若干変更する。

---

# 12. Mob共通AI

Mobは常に、

**最寄りの有効な敵**

をターゲットとして取得する。

基本AI：

```text
最寄りの敵を探索
↓
ターゲット決定
↓
攻撃範囲外なら接近
↓
攻撃範囲内なら攻撃
↓
ターゲットが無効になった場合は再探索
```

初期段階では複雑な経路探索や回り込みAIは必須としない。

---

# 13. 近接Mob

## 基礎仕様

```text
タイプ：近接
移動速度：0.5
攻撃範囲：前方0.8
ダメージ：5
攻撃間隔：1秒
```

最寄りの敵へ接近する。

対象が前方0.8以内に入った場合、1秒ごとに攻撃する。

---

# 14. 遠距離Mob

## 基礎仕様

```text
タイプ：遠距離
移動速度：0.4
攻撃範囲：前方1.3
ダメージ：5
攻撃間隔：1.5秒
```

最寄りの敵へ接近する。

対象が前方1.3以内に入った場合、1.5秒ごとに攻撃する。

現時点では初期検証用の短射程遠距離Mobとして扱う。

今後、より長射程のMobや弾を使用するMobへ拡張可能。

# 15. Mobの見た目

初期プロトタイプでは、近接Mobと遠距離Mobの判別が可能な程度に外見を変更する。

例：

```text
近接Mob
→ 太め / 近接武器風

遠距離Mob
→ 細め / 射撃武器風
```

具体的なデザインはTBD。

# 16. Mob拡張方針

将来的には以下のようなMobを追加可能とする。

- 高速Mob
- 高耐久Mob
- 遠距離射撃Mob
- 範囲攻撃Mob
- 突進Mob
- 支援Mob
- 状態異常Mob
- 強Mob
- エリートMob
- ボス

AIや攻撃処理はMob固有コードだけで実装せず、可能な限り設定データや共通Behaviorを利用して拡張可能にする。
