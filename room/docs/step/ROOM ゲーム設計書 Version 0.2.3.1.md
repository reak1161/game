# ROOM ゲーム設計書
## Version 0.2.3.1

> Game Title: **ROOM**  
> Full Title: **Royale Of Outlaws & Monsters**  
> Version: **0.2.3.1**  
> Status: Hotfix / Visual & Camera Adjustment

---

# 1. Version 0.2.3.1 更新概要

Version 0.2.3.1では、高速移動時の迫力不足・視認性不足を改善するため、カメラ追従方式を調整する。

主な対象：

```text
ダッシュ
ボルテッカー
メガボルテッカー
その他高速移動
```

---

# 2. 問題点

高速移動中もカメラの注視点がアウトローへ強く追従しすぎることで、

```text
キャラクターが画面中央付近に固定される
↓
実際には高速移動していても
画面上ではキャラクター自身があまり動いて見えない
↓
移動の迫力・軌道の分かりやすさが低下
```

する問題がある。

特にメガボルテッカーでは、ジグザグ軌道がカメラ移動によって相殺されやすい。

---

# 3. 高速移動時の注視点

高速移動中は、

**カメラ注視点をアウトロー位置へ即座に固定しない。**

アウトローが先に移動し、その後からカメラが追従する。

概念：

```text
高速移動開始
↓
アウトローが画面中央から先へ飛び出す
↓
カメラが少し遅れて追従
↓
移動終了後に自然に追いつく
```

---

# 4. デッドゾーン方式

プレイヤーが画面中央から少し動いただけでは、カメラを大きく動かさない。

距離に応じて追従強度を変える。

概念例：

```text
中心から近い
→ カメラ追従を弱くする

少し離れる
→ 緩やかに追従

大きく離れる
→ 強めに追従
```

具体的な距離・追従係数はプレイテストで調整する。

---

# 5. ダッシュ

ダッシュ中は、

```text
移動距離：2.5
移動時間：0.2秒
```

の既存性能を維持する。

今回のパッチでは移動速度自体を変更せず、

**カメラ追従の調整によって高速感を強化する。**

---

# 6. ボルテッカー

ボルテッカーもダッシュ同様、

**アウトローを常に画面中央へ固定しない。**

アウトローが先行して移動し、カメラが後から追いつくことで、

```text
突進感
高速感
残像の視認性
```

を強化する。

---

# 7. メガボルテッカー

メガボルテッカーでは特に、

**ジグザグ軌道へカメラが完全追従しない**

ようにする。

アウトロー自身が画面内を、

```text
左
→ 右
→ 前方
```

へ高速で移動する様子を見せる。

カメラは細かな左右移動を追いすぎず、

**全体としての進行方向へ緩やかに追従する。**

---

# 8. 高速移動終了後

高速移動終了後は、

カメラが現在のアウトロー位置へ自然に収束する。

瞬時に中央へ戻さず、

```text
高速移動終了
↓
短時間で追従速度を上げる
↓
アウトロー付近へ収束
```

とする。

---

# 9. カメラ遅延の制限

迫力を優先しすぎて操作性を損なわないよう、

**カメラとアウトローの最大距離を制限する。**

アウトローが画面端まで飛び出して見失うような状態にはしない。

---

# 10. 残像との組み合わせ

既存仕様の、

```text
ボルテッカー
メガボルテッカー
→ 高速移動中に残像表示
```

と組み合わせる。

今回のカメラ調整により、

```text
アウトロー本体
+
残像
+
移動軌道
```

を同時に視認しやすくする。

---
