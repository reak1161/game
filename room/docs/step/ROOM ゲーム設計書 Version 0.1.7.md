# 2. 距離・サイズ基準

ゲーム内の距離・半径・幅・サイズ・回転半径等は、

**プレイヤーキャラクターのデフォルト当たり判定直径を1.0**

として定義する。

```text
プレイヤーのデフォルト当たり判定直径 = 1.0
```

例：

```text
前方4
→ プレイヤー直径4個分の距離

幅1
→ プレイヤー直径1個分

サイズ0.7
→ プレイヤー直径の70%

半径1.5
→ プレイヤー直径1.5個分

回転半径2
→ プレイヤー直径2個分
```

以降、特別な記載がない限り、この相対単位を使用する。

# 3. 攻撃範囲表記ルール

従来の、

```text
前方4、範囲1
```

のような曖昧な表現を避ける。

攻撃形状に応じて以下の表記を使用する。

## 3.1 地点指定型

```text
前方4地点、半径1
```

意味：

プレイヤーから前方4の地点を中心として、半径1の円形範囲。

---

## 3.2 直線範囲型

```text
前方4、幅1
```

意味：

プレイヤーから前方4まで続く、幅1の直線または矩形範囲。

---

## 3.3 扇形

```text
前方1.7、角度45°
```

意味：

プレイヤーを起点として、前方1.7までの45°扇形。

---

## 3.4 投射物

```text
射程5、サイズ0.7
```

意味：

サイズ0.7の投射物が最大5まで移動する。

---

## 3.5 自身中心円形

```text
自身中心、半径1.5
```

意味：

自身を中心とした半径1.5の円形範囲。

---

# 4. 共通デフォルト値

個別の能力・攻撃に数値指定がない場合、以下を使用する。

```text
回転半径：2
弾速：5/s
```

個別に数値が指定されている場合は、その数値を優先する。

優先順位：

```text
個別指定
>
共通デフォルト値
```

例：

```text
フレイムダンス
→ 回転半径の指定がないため2を使用

つらなるつらら
→ 弾速5/sを使用

プレイヤー遠距離通常攻撃
→ 個別指定2/sのため2/sを使用
```

# 5. テスト用Mobスポーン仕様

テスト環境ではMobスポーンを以下の暫定仕様とする。

## スポーン間隔

```text
7～10秒ごと
```

各スポーン時にランダムな間隔を再抽選する。

## スポーン数

```text
2～5体
```

1回のスポーンごとにランダムで決定する。

---

# 6. 1分経過前のMob

ゲーム開始から1分未満では、

```text
雑魚Mobのみ
```

スポーンする。

種類：

- 近接雑魚Mob
- 遠距離雑魚Mob

種類はランダムで決定する。

---

# 7. 1分経過後の中Mob出現

ゲーム開始から1分経過後、スポーンする各Mobについて、

```text
20%
```

の確率で雑魚Mobの代わりに中Mobを出現させる。

つまり各個体単位で、

```text
80%：雑魚Mob
20%：中Mob
```

として判定する。

中Mobになった場合、

```text
近接
または
遠距離
```

をランダムで決定する。

# 12. ボルトショック発生タイミング

3つの攻撃エリアは手前から奥へ順番に発生する。

発生間隔：

```text
0.15秒
```

発生タイミング：

```text
0.00秒：1発目
0.15秒：2発目
0.30秒：3発目
```

従来の0.5秒かけて3発という仕様から変更する。

---

# 13. ボルトショック配置範囲

3つの攻撃エリアを以下の区間に配置する。

## 開始位置

```text
プレイヤーの当たり判定前端 + 0.5
```

プレイヤー直径が1.0のため、プレイヤー中心から見た場合は、

```text
0.5 + 0.5 = 前方1.0
```

付近が開始位置となる。

## 終了位置

```text
プレイヤー中心から前方3.2
```

この開始位置から終了位置までの間に、3つの攻撃エリアを自然に配置する。

固定座標ではなく、

- 開始位置
- 終了位置
- 攻撃数
- 半径

から配置位置を算出できる構造を推奨する。

---

# 14. 帯電エリア

ボルトショックで発生した各攻撃エリアは、攻撃後に「帯電エリア」となる。

```text
持続時間：6秒
```

プレイヤーが帯電エリアへ侵入した場合、

```text
帯電スタック +1
```

し、その帯電エリアは即座に消滅する。

1つの帯電エリアから帯電を取得できるプレイヤーは1人のみ。
