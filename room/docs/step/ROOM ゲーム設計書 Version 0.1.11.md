# 5. 遠距離モンスターの探知と接近

遠距離モンスターの「探知範囲」は、攻撃可能距離そのものではなく、

**追跡対象として敵を認識する範囲**

とする。

探知範囲内へ敵が入っても、その場で移動を停止しない。

---

# 6. 遠距離モンスターの基本行動

基本フロー：

```text
敵が探知範囲外
→ 通常行動

敵が探知範囲内
→ 対象として認識
→ 対象を追跡
→ 射程内に入るまで接近

敵が射程内
→ 接近を停止
→ 攻撃開始
```

例：

```text
射程：3
探知範囲：3.6
```

対象が距離3.5に入った場合：

```text
探知成功
→ 対象へ接近
→ 距離3以内まで移動
→ 攻撃開始
```

探知した瞬間の距離から攻撃するわけではない。

# 7. 攻撃中に対象が射程外へ出た場合

攻撃対象が再び射程外へ移動した場合、

```text
攻撃可能距離外
→ 再接近
→ 射程内へ入ったら攻撃再開
```

とする。

# 8. レベルアップ選択キュー

レベルアップ時のアビリティ・バフ等の選択を完了していない状態で、さらにレベルアップする場合がある。

その場合、新しい選択画面で現在の選択を上書きしない。

**選択イベントは発生した順番に処理する。**

---

# 9. レベルアップ選択の処理順

例：

```text
Lv2到達
→ Lv2の選択画面を表示
```

Lv2の選択を行わないままLv3へ到達：

```text
Lv2の選択画面をそのまま表示
Lv3の選択は待機
```

Lv2の選択完了：

```text
Lv2選択UIを閉じる
→ Lv3選択UIを即座に表示
```

---

# 10. 選択イベントの待機方式

内部的には、未処理の選択イベントをキューとして保持する。

概念例：

```text
pendingChoices = [
    Lv2,
    Lv3,
    Lv4
]
```

処理方式：

```text
FIFO
```

つまり、

**最も古く発生した選択から順番に処理する。**

---

# 11. レベルアップ選択中のリアルタイム進行

既存仕様と同様、

- 選択中もゲームは停止しない
- WASD移動可能
- モンスターも行動する
- 他アウトローも行動する
- クールダウンも進行する
- 経験値も獲得可能
- さらにレベルアップすることも可能

とする。

その結果発生した追加選択は待機キューへ追加する。

# 12. バブルランチャー仕様変更

水属性アビリティ

**「バブルランチャー」**

の泡のヒット処理を変更する。

---

# 13. バブルランチャーの現在仕様

バブルランチャーは5個の泡を発射する。

```text
泡の数：5
発射時間：約2秒
発射間隔：ランダム
発射方向：ランダム

移動速度：0.4～1.2/s
移動距離：0.5～1.8

停止後残存時間：最大5秒
ダメージ：💧6
```

---

# 14. 泡のヒット処理

泡が敵に接触し、攻撃判定が成立した場合、

```text
💧6ダメージ
↓
その泡は即座に消滅
```

とする。

---

# 15. バブルランチャーの貫通

泡は貫通しない。

1個の泡が1体の敵へダメージを与えた時点で消滅する。

そのため、

```text
1個の泡
→ 最大1回の攻撃判定
```

となる。

---

# 16. 継続ヒットルールとの関係

バブルランチャーには、

```text
同一攻撃判定の継続接触時、
1秒ごとに再ヒット
```

という共通ルールを適用しない。

以前の、

```text
泡が残り続けて1秒ごとに再ダメージ
```

という扱いは廃止する。
