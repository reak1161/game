# 1. Version 0.1.5 更新概要

Version 0.1.5では、主に以下を変更・追加する。

- ゼウス「ボルトショック」の発生タイミング変更
- プレイヤー近接通常攻撃の範囲攻撃化
- プレイヤー遠距離通常攻撃の射程・弾サイズ変更
- メロディアの攻撃タイプ明記
- メロディア「調律」エリアの追従仕様追加
- 五線譜攻撃のダメージ・消滅仕様追加
- ダッシュ系統の移動時間短縮

# 2. ゼウス Q「ボルトショック」

## 2.1 基本仕様

```text
名称：ボルトショック
CD：14秒
攻撃エリア数：3
各攻撃エリア半径：0.5
各攻撃ダメージ：⚡20
```

---

# 3. ボルトショック発生タイミング

3つの攻撃エリアは、手前から奥へ順番に発生する。

従来の「0.3秒間隔」ではなく、

**合計0.5秒かけて3発発生**

する仕様へ変更する。

均等間隔の場合：

```text
0.00秒：1発目
0.25秒：2発目
0.50秒：3発目
```

攻撃エリアの配置仕様、帯電エリア仕様は既存仕様を継続する。

---

# 4. プレイヤー近接通常攻撃

プレイヤーの近接通常攻撃を、単体攻撃から前方範囲攻撃へ変更する。

## 基本仕様

```text
攻撃タイプ：近接
攻撃間隔：0.8秒
射程：前方1.7
攻撃角度：前方45度
対象：範囲内の複数の敵
ダメージ：キャラクターの基礎攻撃力
```

攻撃範囲内に複数の有効対象が存在する場合、すべてに通常攻撃ダメージを与える。

概念：

```text
       ＼   攻撃範囲   ／
        ＼           ／
         ＼         ／
          Player →
```

---

# 5. プレイヤー遠距離通常攻撃

遠距離通常攻撃を以下へ変更する。

```text
攻撃タイプ：遠距離
攻撃間隔：1秒
射程：前方2.9
弾サイズ：0.2
ダメージ：キャラクターの基礎攻撃力
```

基本的に前方へ弾を射出する。

弾速はTBD。

特別な能力による変更がない限り、命中した敵へダメージを与える。

# 6. メロディア 基礎ステータス補足

メロディアの通常攻撃タイプを明示する。

```text
名前：メロディア
HP：300
攻撃タイプ：遠距離
攻撃力：8
移動速度：1.0
```

通常攻撃には共通の遠距離通常攻撃仕様を適用する。

---

# 7. メロディア Q「調律」エリア追従

調律エリアは、方向指定中にプレイヤーへ追従する。

## Q長押し中

- マウスカーソル方向に応じて調律エリアの向きが変化する。
- プレイヤーがWASDで移動した場合、調律エリアもプレイヤーとの相対位置を維持して移動する。
- 調律エリアがその場に置き去りになることはない。

概念：

```text
Player移動
    ↓

Player ── 調律エリア

両方が同時に移動
```

Qを離した時点で、その時点の位置・向きを基準として調律入力フェーズへ移行する。

---

# 8. 五線譜攻撃

特殊旋律を使用しない通常の3音入力では、五線譜攻撃を発動する。

## 基本仕様

```text
音符数：3
1発あたりダメージ：15
最大射程：6
速度：4/s
音符サイズ：0.7
```

3つ目の音が確定した瞬間に発射する。

---

# 9. 五線譜攻撃の命中処理

各音符は独立した弾として扱う。

敵へ命中した場合：

```text
15ダメージ
↓
その音符は即座に消滅
```

貫通はしない。

各音符は別々の敵へ命中することが可能。

---

# 10. ダッシュ系統 共通変更

ダッシュおよびダッシュ派生能力の移動時間を変更する。

従来：

```text
0.5秒
```

変更後：

```text
0.2秒
```

---

# 11. アビリティ「ダッシュ」

変更後：

```text
入力：Space
移動距離：前方2.5
移動時間：0.2秒
CD：7秒
```

その他の仕様は既存仕様を継続する。

---

# 12. アビリティ「ボルテッカー」

変更後：

```text
取得条件：ダッシュ
入力：Space
移動距離：前方4
移動時間：0.2秒
ダメージ：⚡10
CD：7秒
```

命中した敵へ⚡10ダメージを与える。

ダブルダッシュ等によるストック数増加も引き続き適用される。

---

# 13. ダッシュ派生の標準移動時間

今後追加されるダッシュ系統の派生能力についても、個別指定がない場合は、

```text
移動時間：0.2秒
```

を標準値とする。

ただし特殊能力として異なる移動時間を設定することは可能。
