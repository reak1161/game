# 2. 遠距離モンスターの攻撃仕様

遠距離モンスターは、

```text
探知範囲
射程
```

を別ステータスとして持つ。

## 2.1 探知範囲

探知範囲は、

**敵を認識して攻撃を開始する距離**

を表す。

敵が探知範囲内に入った場合、遠距離モンスターは攻撃行動を開始する。

---

# 3. 遠距離モンスターの射程

射程は、

**発射した弾が移動できる最大距離**

を表す。

探知範囲と射程は必ずしも一致しない。

そのため、

```text
敵を探知して攻撃を開始したが、
対象が弾の最大射程より遠い
```

という状況も発生し得る。

---

# 4. 遠距離モンスターの探知範囲

個別指定がない場合、遠距離モンスターの探知範囲は、

```text
射程 +20%
```

とする。

計算式：

```text
探知範囲 = 射程 × 1.2
```

例：

```text
射程1.3
→ 探知範囲1.56
```

```text
射程3
→ 探知範囲3.6
```

個別に探知範囲が指定されている場合は、その値を優先する。

---

# 5. 遠距離モンスターの弾速

遠距離モンスターの投射物には弾速を設定する。

個別指定がない場合：

```text
弾速：5/s
```

を使用する。

これは既存の投射物共通デフォルト値と同じ。

# 8. モンスター撃破時のコイン獲得

モンスターを撃破した場合、経験値とは別にコインを獲得する。

## 雑魚モンスター

```text
取得コイン：4～7
```

## 中モンスター

```text
取得コイン：10～15
```

各撃破時に指定範囲内から取得量を決定する。

近接・遠距離で取得量の差は設けない。

---

# 9. 時間経過によるコイン獲得

アウトローは時間経過によってもコインを獲得する。

```text
毎秒：1.7コイン
```

生存中は継続して加算される。

例：

```text
1分
→ 約102コイン

5分
→ 約510コイン

10分
→ 約1020コイン
```

モンスター討伐によるコインは、この時間経過収入とは別に加算する。

# 10. アイテム

ショップ等から取得できる消費型の能力を、

```text
アイテム
```

として扱う。

現時点では主に、一時的なバフを得る消費アイテムを想定する。

---

# 11. アイテム所持数

アウトローが同時に所持できるアイテムは最大3個。

```text
最大所持数：3
```

各アイテムは個別のスロットに格納する。

---

# 12. アイテム使用キー

アイテムスロットは以下のキーに対応する。

```text
1：アイテムスロット1
2：アイテムスロット2
3：アイテムスロット3
```

対応キーを押すことで、そのスロットのアイテムを使用する。

使用後、そのアイテムは消費され、スロットは空になる。

# 16. 防御系効果の表記

今後、防御・ダメージ軽減系の効果は、

```text
被ダメージ軽減 +○%
```

という表記を基本とする。

例：

```text
被ダメージ軽減 +20%
```

意味：

```text
受けるダメージを20%軽減する
```

内部実装上の計算方法と、ゲーム上の表示文言は分離して扱う。
