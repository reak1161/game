# ROOM Version 0.1.3 追加仕様

## 経験値テーブル暫定式

レベルアップ必要経験値は、

**二次関数をベースとし、Lv5・10・15・20・25の節目で恒久的な段差を加える方式**

とする。

現時点では以下の二次関数を暫定採用する。

\[
XP_{base}(L)=4.031L^2+2.979L+13.409
\]

`L` は現在レベルを表し、`LvL → Lv(L+1)` に必要な経験値の基礎値として使用する。

さらに、Lv5の倍数へ到達する直前には追加経験値を加算する。

段差はそのレベルのみの一時的な増加ではなく、以降の必要経験値にも継続して影響する。

また、後半ほど段差量自体も若干大きくする。

### 現時点の確定値

| レベル | 必要XP |
|---|---:|
| Lv1 → 2 | 20 |
| Lv2 → 3 | 37 |
| Lv3 → 4 | 57 |
| Lv4 → 5 | 95 |
| Lv5 → 6 | 130 |
| Lv6 → 7 | 176 |

以降の値は暫定計算式を使用する。

### 注意

この計算式および各レベルの必要経験値は、ゲームテンポ・Mob経験値・平均到達レベル等のテスト結果に応じて今後変更する可能性が高い。

実装時は数式や経験値テーブルをゲームロジックへ直接ハードコードせず、容易に変更可能な設定として管理する。

## 雑魚Mob

雑魚MobのHPを以下とする。

```text
HP：30
```

近接Mob・遠距離Mobともに、初期テスト段階ではHP30を使用する。

既存仕様：

### 近接Mob

```text
HP：30
移動速度：0.5
攻撃範囲：前方0.8
ダメージ：5
攻撃間隔：1秒
経験値：3～5
```

### 遠距離Mob

```text
HP：30
移動速度：0.4
攻撃範囲：前方1.3
ダメージ：5
攻撃間隔：1.5秒
経験値：3～5
```

## テスト用Mobスポーン

初期プロトタイプでは、

```text
スポーン間隔：10秒
```

とする。

10秒ごとにMobをランダムでスポーンさせる。

スポーンするMobの種類は、

- 近接Mob
- 遠距離Mob

からランダムに決定する。

スポーン位置も有効なマップ範囲内からランダムに決定する。

この10秒間隔はテスト用の暫定値であり、本番仕様ではMob密度、プレイヤー人数、経過時間、エリア等に応じたスポーンシステムへ変更する予定。
