# 2. ゼウス Q「ボルトショック」変更

## 2.1 基本仕様

```text
名称：ボルトショック
CD：14秒
攻撃エリア数：3
各攻撃エリア半径：0.5
各攻撃ダメージ：⚡20
```

```text

```

へ変更する。

# 3. ボルトショック攻撃エリア配置

ボルトショックは、プレイヤー前方に3つの円形攻撃エリアを生成する。

攻撃範囲全体は、

```text
開始：
プレイヤー自身の当たり判定前端

終了：
プレイヤーから前方2.7地点の終端
```

に収まるよう配置する。

3つの攻撃エリアは、この開始端から終了端まで自然に繋がるように配置する。

固定座標を直接指定するのではなく、

- 開始端
- 終了端
- 攻撃エリア数
- 攻撃エリア半径

から配置位置を算出できる構造を推奨する。

---

# 4. ボルトショック発生順

3つの攻撃エリアは同時発生しない。

プレイヤーに近いものから順番に発生する。

```text
0.0秒：1つ目
0.3秒：2つ目
0.6秒：3つ目
```

発生間隔：

```text
0.3秒
```

これにより、雷撃がプレイヤー前方へ走っていくような表現とする。

---

# 5. 帯電エリア

ボルトショックによって攻撃された地点には「帯電エリア」が残る。

## 5.1 持続時間

```text
6秒
```

6秒以内に誰にも取得されなかった場合、その帯電エリアは自然消滅する。

---

# 6. 帯電エリア取得

プレイヤーが帯電エリアへ侵入した場合、

```text
そのプレイヤーの「帯電」スタック +1
```

とする。

スタックを付与した帯電エリアは、その瞬間に消滅する。

つまり、1つの帯電エリアから帯電を取得できるプレイヤーは1人のみ。

```text
帯電エリア
    ↓
Player A が接触
    ↓
Player A：帯電 +1
    ↓
帯電エリア消滅
```

複数プレイヤーが同一エリアから帯電を取得することはできない。

---

# 7. 「帯電」状態

既存仕様を継続する。

帯電はスタック可能な状態異常 / 強化状態。

## ゼウスが取得

1スタックにつき：

```text
移動速度 +10%
攻撃力 +3%
```

## ゼウス以外が取得

1スタックにつき：

```text
移動速度 -5%
毎秒1.2ダメージ
```

帯電自体の持続時間：

```text
10秒
```

最大スタック数および再取得時の持続時間処理はTBD。

# 8. メロディア Q「調律」仕様変更

従来想定していた、

```text
Qを長押ししながら3回のカーソル入力を行う
```

方式は廃止する。

WASD移動と同時にQ長押し操作を継続する負担を減らすため、以下の二段階操作へ変更する。

---

# 9. 調律：フェーズ1「方向指定」

Qを長押ししている間、

**マウスカーソル方向に合わせて調律エリアを移動・回転させる。**

```text
Player
   ↓

      [ 調律エリア ]

            ← Cursor
```

カーソル方向が変化すると、それに合わせて調律エリアの位置・方向も変化する。

---

# 10. 調律エリア固定

Qを離した瞬間、

```text
調律エリアの位置
調律エリアの向き
```

を固定する。

以降、Qを押し続ける必要はない。

固定された調律エリアに対してカーソル操作を行い、3つの音を入力する。

---

# 11. 調律エリア

調律エリアは、

```text
5つの選択エリア
```

から構成される。

五線譜をイメージした横並び / 5段階の領域として表示する。

概念：

```text
──────── ①
──────── ②
──────── ③
──────── ④
──────── ⑤
```

各領域が1つの音の入力位置となる。

---

# 12. 調律エリアの射程

調律エリアの配置可能範囲は、

```text
射程3
```

程度とする。

調律エリア内で最もプレイヤーから遠い位置が、おおよそプレイヤーから3程度になる。

---

# 13. 調律の入力方法

音を1つ選択するには、

**調律エリア外から、5つのいずれかの領域へカーソルを侵入させる。**

侵入した瞬間、その領域を1音として確定する。

例：

```text
エリア外
↓
③へ侵入
↓
1音目：③
```

---

# 14. 次の音を入力する条件

1つの音を選択した後、そのまま別の調律エリアへカーソルを移動しても次の入力とはならない。

次の音を選択するには、

```text
選択
↓
調律エリア外へカーソルを出す
↓
再び任意の調律エリアへ侵入
```

する必要がある。

つまり、

```text
Outside → Area → Outside → Area → Outside → Area
```

で3音を入力する。

---

# 15. 調律入力例

例えば、

```text
3 → 5 → 2
```

と入力する場合：

```text
① カーソルを③へ入れる
   → 1音目確定

② 調律エリア外へ出す

③ カーソルを⑤へ入れる
   → 2音目確定

④ 調律エリア外へ出す

⑤ カーソルを②へ入れる
   → 3音目確定

⑥ 攻撃発動
```

3音目を確定した瞬間に攻撃する。

---

# 16. 音符配置順

入力した3つの音は、

**先に選択した音ほどプレイヤーから遠い位置**

に配置する。

```text
Player

③
     ②
          ①
```

つまり、

```text
1音目：最も奥
2音目：中央
3音目：最も手前
```

となる。

各音符の上下方向の位置は、選択した5つの調律エリアによって決定する。

---

# 17. 通常の五線譜攻撃

特殊な入力組み合わせによる特殊スキルについては、現段階では実装対象外とする。

まずはすべての3音入力について、

**通常の五線譜攻撃**

として処理する。

特殊な旋律・組み合わせ効果については後のバージョンで追加する。

---

# 18. 五線譜攻撃

3つ目の音が確定した瞬間、配置された3つの音符を前方へ射出する。

## 基本値

```text
音符数：3
最大射程：6
速度：4/s
音符サイズ：0.7
ダメージ：TBD
```

---

# 19. 五線譜攻撃の射程

「射程6」は、

**プレイヤー位置を基準とした最大到達地点**

を意味する。

音符が調律時点ですでにプレイヤーから離れた場所に配置されている場合、その分だけ実際の移動距離は短くなる。

例：

```text
Player
0────────3────────6
         ↑        ↑
      奥の音符   最大到達点
```

プレイヤーから3の位置に生成された音符の場合、

```text
実際の移動距離：約3
```

となる。

# 21. 実装上の調律状態

調律は複数フェーズを持つため、状態として管理することを推奨する。

概念例：

```text
IDLE
↓ Q長押し
AIMING
↓ Qを離す
INPUT_WAITING
↓ 1音目
INPUT_1
↓ Outside
INPUT_WAITING
↓ 2音目
INPUT_2
↓ Outside
INPUT_WAITING
↓ 3音目
FIRE
↓
IDLE
```

状態名や実装方法自体は固定しない。

# 22. 調律入力判定

調律エリア内にカーソルが存在するだけでは連続入力しない。

次の入力を許可するためには、

```text
一度すべての調律エリアの外へ出た
```

ことを確認する。

実装時には例えば、

```text
canSelectNextNote
```

等の状態を持つ。

概念：

```text
エリア侵入
→ 音を確定
→ canSelectNextNote = false

エリア外へ退出
→ canSelectNextNote = true
```

再度侵入した際に次の音を確定する。
