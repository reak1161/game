# 1. Version 0.1.13 更新概要

Version 0.1.13では、主に以下を追加・変更する。

- ゲーム外でアビリティ・スキル等を確認できる一覧画面を追加
- メロディア「調律」の選択エリア幅を具体化
- 調律で生成される音符の横方向の射出位置を明確化
- 大モンスターを追加
- 1分以降のモンスター出現カテゴリを拡張
- 大モンスター近接・遠距離の基本個体を追加
- 特殊行動を持つ大モンスター「魔女」を追加
- 遠距離モンスターに距離維持AIを追加
- 大モンスター以降では単純な近接・遠距離以外の特殊個体も登場可能とする

# 4. 一覧画面のデータ管理

ゲーム外一覧は、実際のゲームで使用している定義データから表示を生成する。

例：

```text
AbilityDefinition
SkillDefinition
OutlawDefinition
```

説明用の数値を別途手入力して二重管理しない。

ゲームバランス変更時に、

```text
実際の性能
≠
一覧画面の説明
```

となることを防ぐ。

# 6. メロディア「調律」選択エリア

調律エリアには5個の選択エリアを配置する。

各選択エリアの横幅：

```text
0.5
```

合計：

```text
0.5 × 5
= 横幅2.5
```

の選択領域とする。

5つの領域は五線譜をイメージした配置とする。

---

# 7. 調律エリアとマウス操作

既存仕様通り、

```text
Q長押し
→ 調律エリアがアウトローに追従
→ カーソル方向に応じて向きも変化

Qを離す
→ その時点の方向・位置を基準として選択開始
```

とする。

選択は、

```text
エリア外
↓
いずれかの選択エリアへ侵入
↓
1音選択
↓
調律エリア全体の外へカーソルを出す
↓
再度侵入
```

の流れで行う。

内部のエリア間をそのまま滑らせても連続選択にはならない。

---

# 8. 調律の音符射出位置

選択された音符は、

**選択したエリアの横方向中心位置**

から射出する。

例：

```text
左端エリア
→ 左端エリア中央の横位置

中央エリア
→ 中央位置

右端エリア
→ 右端エリア中央の横位置
```

---

# 9. 音符の前後位置

既存仕様通り、3音の前後位置は選択順によって決まる。

```text
1音目
→ 最も遠い

2音目
→ 中間

3音目
→ 最も近い
```

したがって、各音符の初期位置は、

```text
選択したエリアによる横位置
+
選択順による前後位置
```

によって決定する。

---

# 10. 調律音符の既存仕様

音符：

```text
ダメージ：15
サイズ：0.7
弾速：4/s
最大射程：プレイヤー基準6
貫通：なし
```

敵に命中した音符は消滅する。

---

# 11. 大モンスター

新たなモンスターカテゴリとして、

```text
大モンスター
```

を追加する。

大モンスターは中モンスターよりも強力で、経験値・コイン報酬も高い。

大モンスター以降では、

**単純な近接・遠距離だけでなく、固有AIや特殊攻撃を持つ個体も登場する。**

---

# 12. 大モンスターの出現開始

大モンスターは、

```text
試合開始1分後
```

から出現候補に入る。

1分以降の各モンスター生成時：

```text
雑魚モンスター：75%
中モンスター：20%
大モンスター：5%
```

とする。

カテゴリは1回の抽選で決定し、確率判定を別々に行わない。

---

# 13. 大モンスター・近接

基本的な近接型大モンスター。

```text
タイプ：近接

攻撃：18
HP：100
移動速度：0.4

射程：2
探知範囲：13

攻撃間隔：1秒

経験値：20～30
コイン：30～45
```

---

# 14. 大モンスター・遠距離

基本的な遠距離型大モンスター。

```text
タイプ：遠距離

攻撃：20
HP：45
移動速度：0.3

射程：6
認識範囲：7
探知範囲：13

弾速：12/s
攻撃間隔：3秒

経験値：20～30
コイン：30～45
```

個別指定された弾速12/sを使用するため、投射物共通デフォルト5/sは使用しない。

---

# 15. 遠距離モンスターの距離維持AI

通常の遠距離タイプは、アウトローとの距離を一定程度維持しようとする。

目標距離：

```text
自身の射程 × 50%
```

例：

```text
射程6
→ 目標距離3
```

---

# 16. 遠距離モンスターの基本移動

遠距離タイプの基本行動は以下。

```text
敵が探知範囲内
→ 敵を追跡対象として認識

遠すぎる
→ 接近

認識範囲内
→ 射撃可能

目標距離より近すぎる
→ 後退

目標距離付近
→ 距離を維持しながら攻撃
```

探知・認識・射程・距離維持はそれぞれ別概念として扱う。

---

# 17. 特殊大モンスター「魔女」

大モンスターとして、

**魔女**

を追加する。

魔女は通常の近接型・投射物型ではなく、

**指定地点への予兆付き範囲攻撃**

を行う特殊個体。

---

# 18. 魔女 基礎ステータス

```text
名称：魔女

攻撃：18
HP：50
移動速度：0.4

認識範囲：8
探知範囲：13

攻撃可能距離：7以内

攻撃間隔：4秒

経験値：35～44
コイン：48～60
```

---

# 19. 魔女の攻撃

魔女は、自身から、

```text
距離7以内
```

の任意地点を攻撃対象地点として指定する。

攻撃範囲：

```text
指定地点中心
半径0.5
```

---

# 20. 魔女の攻撃予兆

攻撃地点決定後、

**攻撃予兆を表示する。**

予兆表示から、

```text
1秒後
```

に攻撃判定を発生させる。

命中時：

```text
18ダメージ
```

を与える。

攻撃は投射物ではなく、指定地点への時間差範囲攻撃として扱う。

---

# 21. 魔女の距離維持AI

魔女は通常の遠距離モンスターの、

```text
射程 × 50%
```

ルールを使用しない。

固有AIとして、

**アウトローとの距離を最低5以上に保とうとする。**

---

# 22. 魔女が近づかれた場合

アウトローとの距離が5未満になった場合、

```text
アウトローから離れる方向へ移動
```

し、距離5以上を確保しようとする。

安全な距離を確保しつつ、射程7以内の地点へ予兆攻撃を行う。

---

# 23. 特殊モンスター方針

大モンスター以降では、以下のような特殊個体を追加可能とする。

```text
範囲攻撃型
距離維持型
突進型
召喚型
設置攻撃型
特殊移動型
状態異常型
```

そのため、MonsterDefinition / AI実装は、

```text
melee
ranged
```

だけで固定せず、固有行動を追加可能な構造にする。
