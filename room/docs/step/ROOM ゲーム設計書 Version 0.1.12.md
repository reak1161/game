# 2. レベルアップ選択UI

レベルアップ時のアビリティ等の選択は、

**基本的にマウスクリックで行う。**

選択UIは盤面を確認しやすくするため、

**若干透過したデザイン**

とする。

既存仕様と同様、選択中もゲームは停止せず、プレイヤーは移動可能。

---

# 3. 復活地点

5分以内に死亡したプレイヤーは復活可能。

復活地点はマップ内からランダムに選択するが、以下の条件を満たす必要がある。

```text
敵アウトローが付近に存在しない
→ マップ基準10%以内

敵モンスターが付近に存在しない
→ マップ基準3%以内
```

「マップ基準10%」「3%」の具体的な距離換算方法は、最終的なマップサイズ確定時に統一する。

---

# 4. 復活演出

復活地点が決定した後、

```text
2秒かけてスポーン
```

する。

プレイヤー側からは復活地点が事前に確認できる。

復活完了後、

```text
3秒間無敵
```

を付与する。

---

# 5. ゴースト

ゴーストの詳細仕様は、

**本格的なマルチプレイ実装時に設計する。**

現時点では具体的なHP・攻撃・能力等を確定しない。

# 6. マップ外ダメージ

マップ縮小開始時刻：

```text
10:00
```

10分以降、マップ外にいるプレイヤーは継続的にダメージを受ける。

ダメージ量は、

**経過1分ごとに段階的に上昇する。**

開始値：

```text
3ダメージ
```

最終値：

```text
25ダメージ
```

10分以降、時間経過に応じて3から25まで徐々に強化する。

ダメージ発生間隔はTBD。

# 7. モンスターの探知範囲

近接・遠距離モンスターともに、

**探知範囲**

を持つ。

暫定値：

```text
探知範囲：10
```

探知範囲内に敵が入った場合、その敵を追跡対象として接近を開始する。

---

# 8. 遠距離モンスターの認識範囲

遠距離モンスターは、

```text
探知範囲
認識範囲
射程
```

の3つを別々に扱う。

## 探知範囲

敵を発見して追跡を開始する範囲。

## 認識範囲

遠距離モンスターが射撃行動を開始する範囲。

## 射程

発射した弾が飛ぶ最大距離。

---

# 9. 遠距離モンスターの基本行動

```text
敵が探知範囲内
→ 接近開始

敵が認識範囲内
→ 射撃開始
```

認識範囲の具体値はTBD。

弾速は既存仕様通り、

```text
デフォルト：5/s
```

# 10. 状態異常・バフの重複ルール

同一系統・同一効果ソース内でのみ、強弱比較を行う。

---

# 11. 同じ強さの効果

同じレベル・同じ強さの効果を再取得した場合、

**残り時間を加算する。**

例：

```text
移動速度+20%
残り5秒

+ 同じ効果10秒

→ 残り15秒
```

---

# 12. 強い効果と弱い効果

同一系統で異なる強さの効果が同時に存在する場合、

**最も強い効果のみ実際に適用される。**

ただし、弱い効果の残り時間も裏で減少し続ける。

例：

```text
現在：
+40% / 残り10秒

新たに：
+20% / 15秒
```

最初の10秒：

```text
+40%のみ有効
+20%の残り時間も減少
```

10秒後：

```text
+40%終了
+20%は残り5秒
→ +20%が有効になる
```

---

# 13. 効果ソースごとの独立管理

同じ「攻撃力アップ」等でも、

**効果ソースが異なる場合は別枠として扱う。**

例：

```text
帯電による攻撃力アップ
こうげきのポーションSによる攻撃力アップ
エネルギーチャージによる攻撃力アップ
```

これらは互換性を持たず、独立して存在する。

したがって、それぞれ同時に効果を発揮できる。

強弱比較・時間延長ルールは、

**同一効果ID / 同一効果系統内のみ**

に適用する。

---

# 14. 弱体化

メロディア「ピアノ」等による弱体化も、上記の共通ルールを使用する。

同じ強さの弱体化：

```text
時間延長
```

異なる強さ：

```text
強い方を優先
弱い方も残り時間は減少
```

---

# 15. ショップの開き方

ショップ付近で、

```text
Fキー
```

を押すことでショップUIを開く。

ショップを新規に開ける距離：

```text
1.6以内
```

---

# 16. ショップUI

ショップUIは、アビリティ選択UIに近い形式で表示する。

ショップを開いている間も、

```text
ゲーム進行継続
移動可能
```

とする。

---

# 17. ショップの閉鎖距離

ショップを開いた後、プレイヤーがショップから、

```text
距離3以上
```

離れた場合、

**ショップUIを自動で閉じる。**

整理すると、

```text
0～1.6
→ Fで新規に開ける

1.6～3
→ 開いているショップは維持可能
→ 新規には開けない

3以上
→ 強制的に閉じる
```

# 18. ゼウス「帯電」

帯電の最大スタック：

```text
10
```

帯電エリアに触れるたび、

```text
帯電 +1スタック
```

する。

同時に、

```text
帯電効果時間を10秒に更新
```

する。

10スタック時にさらに帯電エリアへ触れた場合、

```text
スタック数は10のまま
効果時間のみ10秒へ更新
```

とする。

---

# 19. ゼウス「電光石火」

電光石火は、

**実際にその瞬間移動している速度**

を基準にCD回復速度を決定する。

通常移動だけでなく、

- ダッシュ
- 紫電一閃
- その他高速移動
- 移動速度バフ
- 移動速度デバフ

も対象。

停止中：

```text
実移動速度0
→ CD回復速度ボーナスなし
```

---

# 20. 電光石火の上限

電光石火によるCD回復速度には、

**上限を設定しない。**

そのため、ダッシュ等の高速移動中も実移動速度をそのまま参照する。

既存基準：

```text
実移動速度1.0
→ 基準

実移動速度2.0
→ CD回復速度+50%
```

---

**スキル使用可能**

とする。

# 27. 凍結蓄積

凍結蓄積は、

```text
0～100%
```

で管理する。

凍結蓄積を新たに受けるたび、減衰開始までの時間を更新する。

---

# 28. 凍結蓄積の自然減衰

最後に凍結蓄積を受けてから、

```text
5秒間
```

新たな蓄積を受けなかった場合、減衰を開始する。

減衰量：

```text
毎秒20%
```

新たに凍結蓄積を受けた場合、

```text
減衰停止
5秒タイマーを再スタート
```

する。

---

# 29. 凍結発生

凍結蓄積が、

```text
100%
```

に到達した時点で、

**凍結状態**

へ移行する。

その瞬間、

```text
凍結蓄積：0%
```

にリセットする。

100%を超えた余剰値は持ち越さない。

---

# 30. 凍結蓄積と凍結状態

以下は別状態として扱う。

```text
凍結蓄積
≠
凍結状態
```

凍結状態中の既存仕様：

```text
最大3秒
移動不能

3秒経過
または
最初にダメージを受ける

→ 凍結解除
```

凍結中に受ける最初のダメージ：

```text
+20%
```

その攻撃後、凍結は即座に解除される。
