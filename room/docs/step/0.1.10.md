# 1. Version 0.1.10 更新概要

Version 0.1.10では、主に以下を追加・変更する。

- コインの内部値と表示値の扱いを分離
- 既存ポーション名称に「S」を追加
- 新アイテム「かいふくポーションS」を追加
- ゼウス「電光石火」の判定基準を変更
- レベルアップ等の選択UIをリアルタイム進行中に表示する仕様を追加

---

# 2. コインの内部管理

コインは内部的には小数点以下を含む数値として管理する。

例：

```text
153.7 Coin
```

時間経過収入：

```text
毎秒 1.7コイン
```

も、小数を切り捨てずそのまま内部値へ加算する。

---

# 3. コイン表示

ゲーム画面上では、小数点以下を表示しない。

例：

```text
内部値：153.7
表示値：153
```

表示方法は原則として小数点以下切り捨てとする。

ただし購入判定等では内部値を使用する。

例：

```text
内部値：249.9
価格：250

→ 購入不可
```

# 9. ゼウス パッシブ「電光石火」仕様変更

従来は、

```text
キャラクターの移動速度ステータス
```

を基準にクールダウン回復速度を計算する想定だった。

これを変更し、

**ゼウスが実際にその瞬間移動している速度**

を参照する。

---

# 10. 電光石火の判定基準

停止中：

```text
実移動速度：0
→ CD回復速度ボーナスなし
```

移動中：

```text
実移動速度：1.0
→ 基準値

実移動速度：1.5
→ CD回復速度 +25%

実移動速度：2.0
→ CD回復速度 +50%
```

基準は既存仕様と同様、

```text
実移動速度1.0を基準
実移動速度2.0で+50%
```

とする。

---

# 11. 電光石火の計算対象

「電光石火」はステータス上の最大移動速度ではなく、

**現在の実移動速度**

を使用する。

そのため、

- 移動速度バフ中
- 減速中
- ダッシュ中
- その他の移動速度変化中

についても、実際の移動速度に応じてCD回復速度が変化する。

停止している場合は、移動速度ステータスが高くてもボーナスを受けない。

詳細な速度サンプリング・ダッシュ中の上限等はTBD。

---

# 12. レベルアップ時のゲーム進行

レベルアップやアビリティ選択が発生しても、

**ゲームはポーズしない。**

ROOMは常時リアルタイム進行を基本とする。

---

# 13. アビリティ・バフ選択UI

アビリティ、スキル関連、その他バフ等の選択肢は、ゲーム画面上へオーバーレイ表示する。

配置候補：

```text
画面上部
```

戦闘視界を可能な限り妨げない位置へ表示する。

---

# 14. 選択中の操作

選択UI表示中もアウトローは操作可能。

少なくとも以下は継続可能とする。

```text
WASD移動
```

ゲームそのものも継続するため、

- 他アウトロー
- モンスター
- 投射物
- 状態異常
- クールダウン
- マップ縮小
- その他ゲーム時間

は通常通り進行する。

---

# 15. 選択UIの基本フロー

```text
レベルアップ
↓
画面上部に候補表示
↓
ゲームは継続
↓
アウトローは移動可能
↓
候補を選択
↓
効果適用
↓
選択UIを閉じる
```

選択方法についてはTBD。

候補：

- マウスクリック
- キーボード
- その他

# 16. 複数選択イベントの競合

選択中にさらにレベルアップするなど、複数の選択イベントが重なった場合の処理はTBD。
