# 1. Version 0.1.14 更新概要

Version 0.1.14では、主に以下を追加・変更する。

- スケーター「アイスブレイク」の攻撃進行時間を短縮
- 大モンスター「魔女」の攻撃中の移動・CD仕様を変更
- アビリティ「アイスピック」の発射方向を交互化
- 新アウトロー「プラウラー」を追加
- プラウラーのパッシブ・Q・E候補を追加
- Q強化「プレデターフォルム」を追加
- プレデターフォルムの撃破ボーナスをトークン方式で管理

---

# 2. スケーター「アイスブレイク」変更

攻撃範囲がプレイヤー側から前方へ進行する時間を変更する。

変更前：

```text
1秒
```

変更後：

```text
0.3秒
```

その他の仕様は維持する。

```text
前方5
幅2
❄20ダメージ
CD20秒
```

攻撃判定はプレイヤー側から先端へ向かって0.3秒かけて進行する。

---

# 3. アビリティ「アイスピック」変更

アイスピックは、2種類の4方向発射パターンを交互に使用する。

## パターンA

```text
上
下
左
右
```

## パターンB

```text
右上
右下
左上
左下
```

発動するたび、

```text
A → B → A → B ...
```

の順番で切り替わる。

既存性能：

```text
発動間隔：2秒
弾数：4
サイズ：0.7
射程：5
弾速：5/s
ダメージ：各❄12
```

# 4. 大モンスター「魔女」変更

魔女の攻撃フローを変更する。

攻撃地点決定後、

```text
予兆表示
↓
1秒間待機
↓
攻撃発動
```

となる。

この予兆1秒間は、

**魔女は移動しない。**

---

# 5. 魔女の攻撃CD

攻撃CDは、

**予兆開始時ではなく、攻撃が実際に発動した瞬間から開始する。**

攻撃間隔：

変更前：

```text
4秒
```

変更後：

```text
3秒
```

したがって、

```text
攻撃地点決定
↓
1秒間予兆・静止
↓
18ダメージ発生
↓
ここから3秒CD開始
```

となる。

# 6. 新アウトロー「プラウラー」

```text
名称：プラウラー

HP：220
タイプ：近接
攻撃力：12
移動速度：1.1
```

モンスターとの戦闘や連続撃破を得意とするアウトロー。

---

# 7. プラウラー パッシブ「捕食者」

モンスターを撃破するたび、

**撃破したモンスターの最大HPの10%分、自身のHPを回復する。**

例：

```text
最大HP30のモンスター
→ HP3回復

最大HP100のモンスター
→ HP10回復
```

参照するのは撃破時の残HPではなく、

```text
モンスター最大HP
```

とする。

# 12. みだれひっかきの方向判定

各攻撃判定の発生時点で、

**現在の視点方向を参照する。**

そのため、連撃中にマウス方向を変更した場合、

```text
1撃目
2撃目
3撃目
```

を別方向へ出すことも可能。

発動開始時の方向へ固定しない。

# 15. プレデターフォルム中のモンスター撃破

プレデターフォルム効果中にモンスターを撃破した場合、

以下の2つが発生する。

```text
1. プレデターフォルムの残り時間を延長
2. 撃破トークンを1個取得
```

---

# 16. プレデターフォルムの時間延長

モンスター撃破時、

```text
残り時間 +2秒
```

する。

ただし延長処理後の残り時間が4秒以下の場合は、

```text
残り時間：4秒
```

にセットする。

例：

```text
残り1秒
↓
+2秒
= 3秒

4秒以下なので
→ 残り4秒
```

---

# 17. 撃破トークン

プレデターフォルム中にモンスターを1体撃破するたび、

```text
撃破トークン +1
```

を取得する。

各撃破トークンは、

```text
取得から2秒
```

で個別に消滅する。

---

# 18. 撃破トークンの効果

現在所持している撃破トークン1個につき、

```text
移動速度 +5%
攻撃力 +5%
```

を追加する。

この効果はプレデターフォルムの基本効果へ加算される。

---


# 20. 撃破トークンの個別タイマー

撃破トークンはまとめて一つのタイマーで管理せず、

**各トークンが個別の2秒タイマーを持つ。**

例：

```text
0.0秒：モンスターA撃破
→ トークンA取得
→ 2.0秒で消滅

0.8秒：モンスターB撃破
→ トークンB取得
→ 2.8秒で消滅
```

この場合、

```text
0.8～2.0秒
→ トークン2個

2.0～2.8秒
→ トークン1個
```

となる。

---

# 21. プレデターフォルム終了時

プレデターフォルムの効果時間が終了した時点で、

```text
基本バフ
撃破トークンによる追加バフ
```

の両方を終了する。

残っている撃破トークンも破棄する。
