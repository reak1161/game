# 1. Version 0.2.3 更新概要

Version 0.2.3では、主に以下を追加・変更する。

- 新アビリティ「アイシクルアロー」を追加
- 新アビリティ「ファイアパンチ」を追加
- 新アビリティ「フロストラン」を追加
- 新アビリティ「エレクトロード」を追加
- ダッシュ未所持時のSpace系アビリティを拡張
- 範囲が事前に分かるスキル・アビリティの長押しプレビュー仕様を追加
- エレクトロード専用の限定プレビュー仕様を追加

# 2. アビリティ「アイシクルアロー」

```text
名称：アイシクルアロー
条件：ダッシュ未所持
発動：Space
CD：8秒
```

前方へつららの矢を発射する。

```text
射程：8
サイズ：0.6
弾速：8/s
ダメージ：❄12
```

敵へ命中しても消滅せず、

**複数の敵を貫通して命中できる。**

---

# 3. アイシクルアローとSpace枠

アイシクルアローは、

```text
条件：ダッシュ未所持
```

のアビリティとして扱う。

取得した場合、Spaceによるアクションとして使用する。

これにより、

```text
ダッシュ系
または
ダッシュを持たない別Spaceアクション
```

という選択肢を作れる。

---

# 4. アビリティ「ファイアパンチ」

```text
名称：ファイアパンチ
条件：近接
CD：4秒
```

通常の直接攻撃が敵へ命中した際、追加ダメージを与える。

追加ダメージ：

```text
🔥 通常攻撃力の40%
```

---

# 5. ファイアパンチのダメージ計算

例：

```text
現在の通常攻撃力：20
```

の場合、

```text
20 × 40%
= 🔥8ダメージ
```

を追加で与える。

これは、

```text
ダメージ+40%
```

ではなく、

**現在の通常攻撃力を参照して発生する別の追加ダメージ**

として扱う。

---

# 6. アビリティ「フロストラン」

```text
名称：フロストラン
CD：5秒
```

最寄りの敵方向へ氷の攻撃体を送り出す。

---

# 7. フロストラン 往路

最寄りの敵が存在する方向へ移動する。

```text
最大射程：5
速度：12/s
半径：0.4
```

---

# 8. フロストラン 滞留

最大移動地点へ到達した後、

```text
2秒間
```

その場に滞留する。

---

# 9. フロストラン 復路

滞留終了後、使用者の元へ戻る。

```text
帰還速度：17/s
```

---

# 10. フロストランのダメージ

往路・滞留中・復路のすべてで攻撃判定を持つ。

敵へ接触している場合、

```text
❄6ダメージ
0.5秒ごと
```

に与える。

現時点では、

**スリップダメージではなく、通常の連続ヒット攻撃**

として扱う。

したがって、共通スリップダメージの防御無視仕様は自動適用しない。

---

# 11. アビリティ「エレクトロード」

```text
名称：エレクトロード
条件：ダッシュ未所持
CD：20秒
```

前方へ電撃の道を展開する。

---

# 12. エレクトロードの展開

```text
最大射程：20
幅：2
展開時間：0.5秒
```

発動地点から前方へ、0.5秒かけて電撃の道を伸ばす。

---

# 13. 壁・障害物との相互作用

エレクトロードが壁や障害物等へ命中した場合、

**その地点から枝分かれする。**

単純に障害物で停止する仕様ではない。

枝分かれの具体的な角度・本数・優先方向等は、実装時に調整可能な構造とする。

---

# 14. エレクトロードの滞留

電撃の道が最大地点まで展開し終わった後、

```text
9秒間
```

その場に滞留する。

---

# 15. エレクトロード上の自分

使用者自身が電撃の道上にいる場合、

```text
移動速度 +20%
```

を得る。

道から離れた場合、この移動速度補正は適用されない。

---

# 16. エレクトロード上の敵

敵が電撃の道上にいる場合、

```text
1スリップダメージ
```

を受ける。

共通スリップダメージ仕様により、

```text
0.5秒ごと
防御系効果を無視
```

する。

---

# 17. 範囲プレビュー

発動前に攻撃範囲や設置位置を確認できるタイプのスキル・アビリティには、

**長押しプレビュー**

を使用可能とする。

---

# 18. プレビュー中の基本操作

対応キーを長押ししている間、

```text
攻撃範囲
設置地点
射線
進行方向
```

等を半透明で表示する。

基本的には、

```text
キー長押し
→ プレビュー表示

キーを離す
→ 発動
```

という操作を想定する。

---

# 19. プレビュー対象

例：

```text
地点指定型攻撃
前方範囲攻撃
扇形攻撃
設置型アビリティ
射線が重要な攻撃
```

等。

すべてのスキルを強制的に長押し方式にするわけではない。

**事前確認が操作上有用なものだけ個別に対応する。**

---

# 20. プレビュー表示の方針

プレビューは、

- 半透明
- 実際の戦闘画面を隠しすぎない
- 射程や範囲を把握できる
- 実際の攻撃範囲と大きくズレない

ことを重視する。

ただし、特殊挙動を持つ能力では正確な最終形状をすべて表示する必要はない。

---

# 21. エレクトロードのプレビュー

エレクトロードは、

```text
最大射程20
障害物で枝分かれ
```

という特殊挙動を持つため、

**実際の完成形をすべてプレビューしない。**

---

# 22. エレクトロードのプレビュー距離

長押し中に表示するのは、

```text
前方5
幅2
```

までとする。

---

# 23. エレクトロードの先端表現

プレビューの先端には、

```text
その先にも伸びる
```

ことが分かる表現を入れてよい。

例：

```text
薄い矢印
フェードアウト
先端の発光
点線
```

等。

最大射程20まで伸びることを視覚的に示す。

---

# 24. 枝分かれのプレビュー

壁や障害物に命中した際の、

```text
枝分かれ位置
枝分かれ方向
最終的な道形状
```

は事前表示しない。

エレクトロードのプレビューは、

**発動方向と初期的な範囲を確認するための補助表示**

として扱う。
