## Version 0.1 以降の追加・変更点

---

# 1. ゲームタイトル決定

ゲームタイトルを以下に決定。

```text
ROOM
```

正式名称：

```text
Royale Of Outlaws & Monsters
```

基本表記は `ROOM` とし、必要に応じて正式名称を併記する。

# 2. アビリティ属性仕様の修正

アビリティ、スキル等は必ずしも属性を持たない。

属性は任意情報とする。

例：

- ダッシュ：属性なし
- ダブルダッシュ：属性なし
- トリプルショット：属性なし
- フレイムダンス：炎
- アイスピック：氷
- せいでんき：雷
- マリンベール：水
- ボルテッカー：雷

実装上は属性なしを許容すること。

将来的な複数属性対応も考慮し、属性を配列として保持する設計も検討可能。

---

# 3. 共通ルール：連続ヒット

同一の攻撃判定が同一対象へ継続して接触している場合、原則として再ヒット間隔は1秒とする。

例：

```text
0.0秒 ヒット
1.0秒 再ヒット
2.0秒 再ヒット
```

個別に再ヒット間隔が指定されている場合は、その設定を優先する。

再ヒット管理は原則として、

```text
攻撃元 × 対象
```

ごとに行う。

# 4. アビリティ「ダッシュ」

## 基本仕様

```text
名称：ダッシュ
属性：なし
```

Lv1のアビリティ選択時のみ出現する。

Lv1の3択には必ず候補として含まれる。

取得しなかった場合、通常のレベルアップ抽選では以降出現しない。

## 効果

```text
入力：Space
移動距離：前方2.5
移動時間：0.5秒
CD：7秒
```

前方はマウスカーソル方向ではなく、ダッシュ時点の移動方向を基準とする既存仕様。

---

# 5. ダッシュストック仕様

「ダブルダッシュ」等によって最大ストック数が2以上になった場合、各ストックは独立してクールダウンを持つ。

例：

```text
最大ストック：2
CD：7秒
```

初期：

```text
2/2
```

1回使用：

```text
1/2
1スタック目のCD開始
```

1スタック目がCD中に再使用：

```text
0/2
1スタック目のCDはそのまま継続
2スタック目のCD開始
```

先にCDが完了したストックから順次回復する。

新しいストックを使用しても、既に進行中の他ストックのCDはリセットされない。

ダッシュ派生能力に変化した場合も、派生先のCD値を用いて同様に管理する。

# 6. アビリティ「フレイムダンス」

```text
名称：フレイムダンス
属性：炎
種別：常時発動 / 自動攻撃
```

## 効果

自分の周囲を3つの炎が回転する。

```text
炎の数：3
炎サイズ：0.7
回転速度：毎秒120度
ダメージ：🔥10
```

同一敵への連続ヒットは共通ルールに従い、原則1秒間隔。

回転半径はTBD。

# 7. アビリティ「アイスピック」

```text
名称：アイスピック
属性：氷
種別：周期発動 / 自動攻撃
```

## 効果

2秒おきに、自分の上下左右4方向からつららを射出する。

```text
発動間隔：2秒
発射数：4
方向：上下左右
つららサイズ：0.7
射程：5
ダメージ：❄12
```

# 9. アビリティ「マリンベール」

```text
名称：マリンベール
属性：水
種別：防御 / 被ダメージ反応
```

自身が泡をまとう。

CDが使用可能な状態でダメージを受けた場合、その1発のダメージを60%軽減する。

```text
ダメージ軽減：60%
CD：10秒
```

発動後CDに入り、CD完了後に再び次の1発へ適用可能。

---

# 10. アビリティ「バブルランチャー」

```text
名称：バブルランチャー
属性：水
種別：自動攻撃 / 設置型
```

## 効果

2秒間の間に合計5発の泡をランダムな間隔で発射する。

各泡のパラメータ：

```text
発射方向：ランダム
速度：0.4～1.2 / 秒
移動距離：0.5～1.8
停止後滞在時間：5秒
ダメージ：💧6
```

泡は指定距離移動後、その場で5秒間漂う。

敵に命中するとダメージを与える。

同一敵への連続ヒットは原則1秒間隔。

バブルランチャー自体の発動周期はTBD。

# 12. アビリティ「ボルテッカー」

```text
名称：ボルテッカー
属性：雷
種別：ダッシュ派生 / 置換
取得条件：ダッシュ所持
```

「ダッシュ」が「ボルテッカー」へ変化する。

## 効果

```text
入力：Space
移動距離：前方4
移動時間：0.5秒
命中ダメージ：⚡10
CD：7秒
```

移動中に命中した敵へダメージを与える。

ダブルダッシュ等によってストック数が増えている場合、ボルテッカーにもそのストック数を引き継ぐ。

---

# 13. アビリティ「ダブルダッシュ」

```text
名称：ダブルダッシュ
属性：なし
種別：ダッシュ強化
取得条件：ダッシュ所持
```

## 効果

ダッシュ系能力の最大ストック数を、

```text
1 → 2
```

へ増加させる。

「ボルテッカー」等へ派生している場合も適用される。

例：

```text
ダッシュ
↓
ボルテッカー
+
ダブルダッシュ

結果：
ボルテッカー最大2ストック
```

各ストックは独立CD制。

# 14. 実装上の追加方針

アビリティは以下のような複数タイプを許容する。

```text
常時発動
周期発動
被ダメージ時発動
通常攻撃変化
既存アビリティ置換
ストック増加
自動攻撃
設置型
条件発動
```

アビリティ種別を固定的なクラス階層だけで表現せず、EffectやTriggerを組み合わせられる構造を優先する。

例：

```text
Trigger:
- Always
- Interval
- OnDamageTaken
- OnDash
- OnBasicAttack

Effect:
- Damage
- DamageReduction
- SpawnProjectile
- ModifyBasicAttack
- ReplaceAbility
- AddCharge
```

これにより、今後のアビリティ追加時に既存コードへの大規模変更を避ける。
