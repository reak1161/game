# ROOM パッチノート

## 2026-10-12 — 操作の反応・再挑戦・訓練場

- 回復中・未取得のスキルを押したとき、使えない理由と残り時間をスキル欄の近くに表示します。使用可能になったスキルは短く光ります。
- アイテムをクリックでも使えるようにしました。空きスロットや常時効果の装備にも案内を表示します。
- 味方の通常弾をアウトローごとの色にし、敵弾は暖色のひし形に変更。弾の軌跡と発射時の光で進行方向が分かりやすくなりました。
- 戦闘不能後に生存時間・到達レベル・撃破数・所持コインを表示。「同じアウトローでもう一度」で最初から再挑戦できます。
- 射撃訓練場に「デコイを前方へ」を追加。近接は1.5、遠距離は2の距離に配置し、ダメージ計測をリセットします。
- 訓練管理で取得済みのスキル・アビリティを表示し、E/Cへの同じスキルの重複選択を無効化しました。

## 2026-10-04 — 戦闘の見やすさ・操作感

- 近接攻撃に射程と方向が分かる扇形ガイドを追加。攻撃が届く敵には目印が付きます。装備による射程の増加も反映します。
- 近接攻撃を振り抜く斬撃に変更。アウトローごとに色を変え、プラウラーには爪の軌跡を追加しました。
- 命中時の火花、読みやすいダメージ表示、撃破時の余韻と獲得XP・コイン表示を追加しました。
- 通常モンスターの近接攻撃予告を、実際の判定に合わせた円形に変更しました。
- HPと残り時間を画面端に集約。Q/E/C/Spaceは使用可能・回復中・未取得を区別し、カーソルやTabで効果を確認できます。
- 自動攻撃の条件と次の近接攻撃までの時間を表示。操作ヘルプにも自動攻撃とアイテム使用の説明を追加しました。
- Escによる中断・復帰を修正。ヘルプ・能力一覧・全体マップの閲覧中と、別のウィンドウへ切り替えた際は戦闘を中断します。
- カメラ移動中も照準を画面上のマウス位置に保ちます。背景グリッドを固定し、OSの「視差効果を減らす」設定では一部の動き・発光を抑えます。

## Prototype 0.2.5 — 2026-10-04

### スキルと成長

- 射撃訓練場に、計測開始からの「平均DPS」と「直近1秒DPS」を並べて表示するようになりました。計測リセットで両方をリセットできます。

- ゲーム開始時は、選んだアウトローの固有Eスキルから選択します。
- 所持済みのスキルは、新しいスキルの抽選に再出現しません。
- Cスキル枠を追加しました。Lv5から、5の倍数のレベルではアビリティ、スキルの順に選択できます。
- E/Cはそれぞれ独立したCDで使用できます。ビルド情報で効果を確認でき、訓練管理でも選択できます。

### 新しい能力

- 「ダイヤモンドダスト」：前方45度へ氷の粒を30発発射します。
- 「ライトニングリレー」：長押しで位置を確認し、離して装置を設置します。すべての装置間に雷が伸び、触れた敵へ継続ダメージと移動速度低下を与えます。
- 「ステルスミッション」：3秒間、移動速度が20%上昇し、自身の表示が半透明になります。敵の認識や攻撃時の解除ルールは今後対応予定です。
- 「バブリンガル」：周囲を回転する泡が、触れた敵の投射物を防ぎます。
- 「漂う鬼火」：自身の左上〜右上を距離0.75で漂います。近くの敵へ突進して炎ダメージを与え、戻ってから次の攻撃に備えます。

### ショップ

- 1つの商品枠に複数の在庫が並ぶことがあります。1個ずつ購入できます。
- 「マズル」「メリケンサック」「達人の帯」を追加しました。所持中に通常攻撃の射程または攻撃力が上がります。

## 2026-10-04 — 効果の確認表示

- ビルド情報の所持アビリティ・アイテム・Q/E・パッシブ・バフ／デバフにカーソルを合わせると、効果説明がポップアップで表示されます。
- Tabキーで項目を選んだ場合も説明を確認できます。

## Prototype 0.2.4 — 2026-09-22

### 新しいアウトロー

- ポセイドンが参戦。3方向の水弾による通常攻撃と、前方を水で撃ち抜く「ハイドロキャノン」を使えます。
- Eスキルで高速移動する「ジェットサーファー」と、敵を引き寄せて波を広げる「タイダルウェーブ」を選べます。

### 新しいアビリティ・戦闘調整

- 急所攻撃、HP再生、アビリティ候補の増加、弱点への追加ダメージなど、9種類の共通アビリティを追加しました。
- 一部の通常モンスターに属性の弱点・耐性が付くようになりました。弱点属性のダメージは2倍、耐性属性のダメージは半分です。
- Q/Eスキルの四角いアイコン外枠で、次の使用までの進み具合が分かるようになりました。
- ボスの位置は近くで発見するとマップに記録されます。発見後は方向案内とマップのマーカーが移動中のボスを示します。

### 今後の対応

- 「バブルリフレクト」と「ビッグウェーブ」は現在使用できません。

## Prototype 0.2.3 — 2026-09-21

- ダッシュを取得しない場合に選べるSpaceアクション「アイシクルアロー」を追加しました。複数の敵を貫通する氷の矢を発射します。

- 「フロストラン」が高速な往路・復路で敵へ触れてもダメージを与えない問題を修正しました。
- 通常攻撃と「ファイアパンチ」の追加ダメージが重なり、片方の数値しか見えない問題を修正しました。
- クリティカル時の表示から「CRITICAL」の文字を削除し、ダメージ数値だけを表示するようにしました。

### 新しい内容（追加）

- 「アイスストーム」を戦闘へ実装しました。氷属性アビリティを3つ所持すると取得候補へ追加されます。
- 3層を回転する30個の氷粒が、命中した敵へ氷ダメージ3を与えます。同じ氷粒の再ヒット間隔は1秒で、別の氷粒はそれぞれ独立して命中します。
- 「アイスストーム」の第1・第3層に対して第2層の配置を半ピッチずらし、氷粒が交互に見えるよう調整しました。
- 連続ヒット時のダメージ数値が対象から遠く離れすぎないよう、表示位置と同時表示数を調整しました。
- 「タイムスリップ」のスタックを共通の4秒CDで1つずつ回復する方式へ変更しました。移動中の再入力でスタックが余分に消費されることも防ぎました。
- 「ダブルダッシュ」も共通の7秒CDで、使用済みストックを1つずつ回復する方式へ変更しました。
