# ROOM 開発進捗

最終更新: 2026-10-12

## 現在の状態

設計書 Version 0.1、追加仕様0.1.1～0.2.5に基づく、ブラウザ向け戦闘プロトタイプを実装中。

### 2026-10-12 入力フィードバック・再挑戦・訓練場

- Q/E/C/Spaceの入力時に、未取得・CD中・ダッシュ方向未入力を短い案内で表示。タイムスリップとダッシュは残存チャージがあれば回復中でも使用可能。失敗案内はゲーム時間で2秒、対象スロットを強調。既存のダメージ・攻撃間隔・射程は変更しない。
- アイテム欄をボタン化し、数字キーと同じ使用処理へ接続。開始時選択中・ポーズ中・戦闘不能中の使用を禁止。空き枠と装備には案内を出し、装備を消費しない。
- 通常弾をアウトロー別の色、敵弾を暖色のひし形へ変更。表示上の軌跡と発射光を追加し、当たり判定・移動速度・射程は維持。動きを減らす設定では軌跡と発光を抑える。
- 戦闘不能時に結果モーダルを開き、生存時間・レベル・撃破数・所持コインを記録。終了後はゲーム更新と回復を停止し、再開操作で戦闘不能状態を解除しない。再挑戦はRoomGameを新規作成する完全な訓練リセットであり、TBDの試合中復活ルールを追加したものではない。
- 訓練場のデコイ配置は近接1.5・遠距離2の距離。画面端では内向きに配置し、プレイヤーは移動させない。計測をリセット。訓練管理は実際の取得状態を反映し、E/Cの重複候補を無効化する。
- 終了処理でショップ・訓練管理・結果画面を閉じ、前のセッションのUIを残さない。フォーム入力中のゲーム用ショートカットを抑制し、Escによるパネル終了は維持。
- 検証: `npm run build`と`npm test`成功。追加検証はCD中入力・チャージ残存・アイテム使用ガード・壁際デコイ配置・戦闘終了後の時間停止と回復停止。Chromeでデコイ配置→近接命中、E連打時の案内、アイテムクリック、取得済み/重複スキル表示、実戦での結果画面→再挑戦（HP240・Lv1・00:00・初期E選択へ戻る）を確認。ブラウザのエラーログなし。

### 2026-10-04 戦闘アニメーション・UI/UX改善

- 近接ガイドと通常攻撃で共通の射程・対象判定を使用。既存の射程1.7、角度45度、間隔0.8秒、敵半径と装備補正を維持。範囲内に対象がいなければ攻撃しない挙動も維持。
- 斬撃は発動時の位置・向き・射程を記録して0.34秒で消える。移動後のプレイヤーへ軌跡を吸着させない。命中・撃破エフェクトには寿命と個数上限を設け、撃破後も最後のダメージと報酬が読めるようにした。
- 通常敵の近接予告は既存の全方向距離判定に合わせて円形。ボスの扇形・直線予告は維持。
- Canvas内のQ/E/C表示をHTMLのQ/E/C/Space欄へ置換。スキル定義・個別CD・タイムスリップとダッシュのチャージ・取得状態を参照。ビルド情報のE名称もDOM依存をなくし定義を直接参照。
- メニュー・モーダル・ウィンドウ離脱の中断で入力と長押しプレビューを解除。Escの既定動作が新規メニューを閉じてしまう問題を修正。全体マップはMまたはEscで閉じて復帰できる。
- 固定グリッドは表示範囲だけ描画。マウスの画面座標を保持し、カメラ追従後にワールド座標を更新。`prefers-reduced-motion`で反動・敵の上下動・画面端の被弾発光などを抑制。
- `npm test`に既存0.2.5検証と`verify-combat-feedback.mjs`を接続。射程境界・角度・攻撃間隔・斬撃原点・撃破報酬の重複防止・ポーズ入力・HUD状態を検証。
- ブラウザで初期選択、通常攻撃の命中、E使用とCD表示、Esc中断・復帰を確認。1920px・1024px・820px幅でHUDを確認。

## 忘れてはならない事項

- 固有指定がない値は共通デフォルトを適用する。固有仕様として明示的にTBDのものは、共通デフォルトで扱える項目を除き独断で確定しない。
- UIとゲームロジックを分離し、キャラクター・スキル・アビリティ等はデータ駆動で追加できる状態を保つ。
- オンライン化ではサーバー権威とし、クライアントからダメージ結果ではなく入力を送信する。
- スキルのクールダウンは効果終了時ではなく発動時から開始する。
- Lv1のアビリティ3択には、ダッシュを必ず1枠含める。ただし取得は任意。
- Lv1でダッシュを取得しなかった場合、Lv2以降の通常レベルアップ抽選にはダッシュを出現させない。
- 0.2.5以降、5の倍数のレベルアップではアビリティ選択→スキル選択の順で行う。各イベントをFIFOへ追加し、片方を省略して上書きしない。
- 調律エリアはQを離してもその場には固定せず、確定した方向を維持して3音入力完了までプレイヤーへ追従する。
- ゼウスの帯電は最大10スタック。帯電エリア取得時はスタックを1増やし、全スタックの効果時間を10秒へ更新する。
- ゼウス以外の帯電は1スタックにつき移動速度-5%・毎秒1.2ダメージ。
- 遠距離通常攻撃は個別指定がない場合、弾速2/sを使用する。
- 凍結は100%蓄積で最大3秒間移動不可。最初の被ダメージだけ20%増加して解除し、多段攻撃の後続ヒットには補正しない。
- 凍結蓄積は最後の付与から5秒後に毎秒20%減衰し、新たな付与で減衰待機を5秒へ戻す。
- 「前方N」は前方Nの終点だけを示すのではなく、原則として自分から前方Nまで続く攻撃距離を示す。個別に配置方法が指定された能力はその指定を優先する。
- 3方向攻撃は個別指定がなければ中央と±30度、ダメージ倍率は個別指定がなければ100%とする。
- プレイヤーの当たり判定は中央の本体円のみ。外側の装飾円、HP・CDゲージ、名前表示は当たり判定に含めない。
- 共通デフォルトは回転半径2、弾速5/s。未指定の標準弾サイズは0.2とする。
- 中Mobの未指定移動速度は同タイプの雑魚Mob、未指定経験値は既存Mob共通値3～5を継承する。
- 「幅N」は全幅Nを意味し、進行軸から左右へN/2ずつ広がる。
- 再ヒット間隔は「個別の攻撃元×対象」で管理する。同じ能力が炎・弾・設置物等を複数生成した場合、それぞれ別の攻撃元として命中判定する。
- 凍結蓄積は最後の付与から5秒後に毎秒20%減衰する。100%到達時に0%へ戻して凍結へ移行し、余剰値は持ち越さない。
- プレイヤーキャラクターは「アウトロー」、PvEの敵は「モンスター」、各段階は「雑魚／中／強モンスター」と表記する。
- モンスター一覧はゲーム用定義を直接参照し、表示専用の数値を重複管理しない。
- 数値表示は原則として整数、端数が必要な場合だけ小数第1位まで表示する。浮動小数点誤差は表示前とHP加減算時に正規化する。
- スタン中もスキル使用可能。現状のモンスターには移動速度-90%を適用し、視界阻害は将来の操作主体を持つ対象向けに保持する。
- 同一効果ソース・同一強度の弱体化は効果量を重ねず残り時間を加算する。異なる強度は強い効果だけを適用し、各残り時間を独立して減らす。
- 遠距離モンスターは探知範囲内で攻撃を開始するが、投射物が射程外まで届かなければ命中しない。
- アイテムは最大3個。訓練モードでは取得経路未実装のため、動作確認用として、すばやさ／こうげき／かいふくのポーションSを各1個初期所持する。
- ポーションの重複規則は設定変更可能な個別タイマーとして保持する。同種を複数所持する取得経路は現時点で用意しない。
- コインは内部値の小数を維持し、HUD表示だけ小数点以下を切り捨てる。購入判定を追加する際は表示値ではなく内部値を使う。
- 電光石火は実移動速度1.0を基準にし、停止中はボーナスなし。ダッシュ中の上限と詳細な速度サンプリングはTBDのため固定上限を設けない。
- 選択中もゲームを進行する。現在の選択方法はマウスクリックで、キーボード等の追加操作は仕様確定後に対応する。
- 選択イベントはFIFOキューで処理し、現在表示中の選択を新しい選択で上書きしない。
- ビルド情報を開くキーはTBD。現時点では画面上の専用ボタンで開閉し、表示中もゲームを進行する。
- モンスターは探知範囲10へ入るまで追跡せず、一度探知した対象は追跡解除条件が確定するまで追跡を継続する。
- 雑魚／中の遠距離モンスターの認識範囲はTBDのため、射撃開始距離は既存の攻撃射程を暫定維持する。大遠距離と魔女は個別指定の認識範囲を使用する。
- 大モンスター枠内の近接／遠距離／魔女の比率は未指定のため、追加変更しやすい均等抽選を現在のデフォルトとする。
- スキル強化はLv10以降の5の倍数だけで抽選する。プレデターフォルムは通常アビリティ候補へ出さず、このスキル強化枠でのみ提示する。
- クリティカルの基本値は確率3%・ダメージ1.5倍。クリティカルは防御系バフを無視し、将来の関連能力で変更できる設定値として管理する。
- 限定条件のない「ダメージ+○%」は通常攻撃・スキル・アビリティなど、アウトロー自身が与えるダメージ全般へ適用する。
- アイスストームは氷属性アビリティ3つ所持を取得条件とし、同じ氷粒から同じ対象への再ヒット間隔は1秒、別の氷粒は独立して命中する。
- Lv1～25のHP・攻撃は0.1.18の暫定式・基準値を設定データとして使用する。必要経験値はLv6→7まで確定表、以降は0.1.3の暫定二次式を使用する。
- 時空管理の対象側CD判定は敵アウトローが存在する対戦実装後に適用する。ソロ訓練では自身のQ/EがCD中のダメージ+5%のみ確認可能。
- ボス個別の出現時間・地点・ステータス・総経験値が未定義のため、実体の生成と報酬分配はデータ確定まで行わない。
- 血液探知は、一度でも攻撃したモンスターと敵アウトローの両方を対象とする。現在のソロ訓練では敵アウトローが存在しないため、モンスター表示のみ動作確認可能。
- 復活地点の「マップ基準10%／3%」はマップサイズ確定待ち。マップ外ダメージは発生間隔、ショップは配置地点が未確定のため未実装。
- かいふくポーションSは被ダメージを受けても現状中断しない。中断有無はTBDとして確定扱いにしない。
- 5分以内の死亡は復活可能。5分経過後は本死亡となり、観戦またはゴーストを選択する。
- 10分でマップ縮小とショップ更新を開始し、20分で最終エリアを確定する。
- 公開用UIには、ファイル構成など内部実装向けのメタ説明を混ぜない。
- 用語は設計書に合わせて統一し、追加語はヘルプまたはドキュメントへ追記する。
- Markdown、TypeScript、HTML、CSSはUTF-8を維持する。
