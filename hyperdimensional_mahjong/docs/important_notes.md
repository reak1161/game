# 忘れてはならない事項

- 固定組の牌種は実牌検証で変えられないため、固定した虹色牌は変化探索から外す。手牌の虹色牌まで除外しない。性能の比較値には対象の手牌・回数・実行環境・測定範囲を残し、一般的な保証として案内しない。

- 固定した副露・カンは面子の牌種構成だけでなく採用した実牌IDと牌種の一致を確認する。別の手牌で固定組を作り直してはいけない。踊り子の候補検証でも固定カンは実牌を使い、仮牌IDと衝突させない。

- 能力カードがない状態を「使用済み」と表示しない。配布枚数・カードごとの状態・使用可否を区別して案内する。一般操作のブラウザー確認を、特定のカード・特殊牌の組み合わせ確認済みという根拠に使わない。

- 虹色の圧縮対子は2枚を1つの変化単位とし、保存された2枚目と展開牌を同時に変化させる。各探索候補で元の属性を復元してから保持条件を判定する。探索中に元の手牌の保存属性を変更しない。最高点の検証は翻だけでなく最終和了点で行う。

- 虹色変化の探索削減で、異なる属性の牌を交換可能と扱わない。赤属性・仮想牌・圧縮牌の枚数差と和了牌による条件を区別する。手牌順で最高和了点が変わらないことを確認する。

- 刻子牌の展開で余る2枚を除く場合も、副露・カンの固定実牌IDを保護する。和了形の面子が同じ牌種だからといって固定牌を別の牌へ置き換えない。多牌と刻子牌で共通の保護ID取得を使う。

- 多牌で余分な牌を除外するとき、副露・カンの固定牌を除外候補にしない。同じ牌種でも別IDの手牌へ置き換えず、特殊効果・赤ドラ・採用牌表示に使う実牌IDを保持する。カンの4枚目は3枚相当の和了形とは別に得点へ反映する。

- 踊り子のタイミングはv0.3がv0.2に優先する。配牌を聴牌にし、通常ツモ番開始時にツモ前の手牌を強制変化する。打牌後の変化はしない。海底の釘の待ち判定は変化後の手牌で行う。嶺上・北抜き・フィナーレでは通常ツモ開始の変化を追加しない。

- 閲覧用の特殊牌ボタンは打牌・牌選択のアクションへ接続しない。伏せ牌と他家の非公開トラップには詳細操作用の属性を付けない。手番中の自分の手牌はタッチの初回で詳細、次回で選択・打牌する既存操作を維持する。

- 特殊牌の状態説明を役成立や操作可能の保証として扱わない。運命の導きは現在のツモ牌IDと和了可否の進行状態を使い、トラップは現在のロン対象IDと過去の河を区別する。牌種条件は局イベントの牌体系で判定する。

- スケスケルトンの予定生成では山・予約・追加ツモを消費しない。既知の借りパク追加ツモは同じ席へ割り当て、その後の予約位置もずらす。予約変化は共通の牌変化処理と合わせ、破竹の勢いでは索子化後の牌名を表示する。未来の任意操作を確定予定として扱わない。

- 踊り子の数字反転は通常1↔9、トランプ1↔13で行い、牌種IDを直接反転しない。形の聴牌だけでは緑一色などの目標役は保証できないため、得点判定による役到達確認を省かない。候補数が増えても役を同じ抽選枠へまとめる。

- 役の変更要因は補完役にも表示する。字一色・緑一色の純粋牌強化では「まであと1面子」という名前になっても純粋牌の説明を省かない。

- 踊り子の十三連宝燈は既存の刻子牌2枚を1と13へ配置する。特殊牌を新たに生成しない。役設定OFF、固定カン、圧縮牌がある場合は候補に追加しない。

- 踊り子の待ち検証は固定カンを各3枚として含む13枚相当の手牌を使う。残り手牌から検証する場合だけ固定カンを加え、カン込みのテンプレートへ二重追加しない。

- 一色三連の同種類条件は3連子にかかり、雀頭にはかからない。構成例やヘルプでも雀頭まで同種類が必要と説明しない。

- 局開始時のポップアップ状態は神経衰弱へ分岐する前に初期化する。画面の開閉状態と演出設定の保存値は別に扱う。

- 神経衰弱の演出設定も通常局と共通の `setMotion` を使う。保存設定とOSの動きを減らす設定を尊重し、演出変更で手番・伏せ牌・CPUタイマーを変更しない。

- ニアピンの一色役補完は雀頭の条件を必ず確認する。連子形では対象の2連子、通常形では対象の3面子が必要。雀頭が別種類の場合や不足2組は補完しない。

- 連子と順子を役判定で混同しない。連子形の3組に通常形4面子の混全帯幺九・純全帯幺九の不足判定を流用しない。

- ニアピンの不足1面子は和了形ごとの組数で判定する。通常形は4組、連子形は3組。連子の末尾は開始数字+3であり、順子の+2を流用しない。

- 純粋牌は一色三連にも適用し、3倍化の後にニアピンで半減する。三連子は一色系役ではないため3倍化しない。

- ニアピンの一色三連は、成立する連子形のうち2連子が同じ種類の場合に補完する。雀頭の種類は一色三連の条件に含めない。一色三連OFFの場合は追加せず、下位の三連子と重ねない。

- 踊り子の拡張対子候補は実手牌13枚・圧縮牌偶数枚・固定カンなしに対応。役は全展開後の枚数から決める。通常形など別解釈が最高点になる場合は、その対子役に到達したとは扱わない。

- 踊り子は特殊牌・圧縮牌の効果を保持した実手牌で候補を検証する。浄化牌による目標役の正当な変換は失敗扱いにしない。合計24回の打ち切りは撤廃し、生成済みの有限候補を確認する。全牌配置を網羅する生成器ではなく、候補なしの場合の変化見送りは暫定方式。

- 千変万化の抽選範囲は局イベントの数牌体系に合わせる。トランプマジックは1～13、通常局は1～9。変化先の13を幺九牌として扱い、赤ドラを新たに生成しない。

- 結果の点数移動は局開始時からの実持ち点差で表示する。和了点だけから再計算しない。未回収の立直供託や前局から持ち越した供託があるため、席の増減合計が常に0とは限らない。

- 対局開始時の設定と要素選択をブラウザー内に保存し、再読み込み後も引き継ぐ。進行中の対局は保存しない。保存値は許可された値と要素IDだけを復元し、破損・保存不可でも開始できるようにする。初期化は対局設定だけを対象とし、演出設定は別に保持する。開始画面の直接操作と要素選択ポップアップの設定を開始前に同期する。

- 数牌の並びや隣接の判定は牌種IDの差ではなく `suitOf` と `rankOf` を使う。トランプマジックの10～13は通常牌と連続したIDではない。十三不塔でも全数字を判定対象にする。

- 局イベントで牌変化先が変わる場合、固定の牌名をログに使わない。変化後の実牌から表示し、カードの基本説明には現在の局イベントの補足を付ける。

- カードの状態表示と操作可否を分ける。「未使用」「繰り返し使用」は現在の手番や対象牌にかかわらず使えるという意味ではない。ニアピンの使用済みフラグだけで継続効果を終了扱いにしない。

- ニアピンで追加成立した混系役にも浄化牌の変換を適用する。混一色から清一色へ変換した場合は純粋牌の3倍対象になり、その後ニアピンで半減する。浄化牌なしの混一色は純粋牌の対象外。

- ニアピンは任意発動型。所持しているだけでは効果を適用せず、各局の `nearPinActive` をfalseへ初期化する。神経衰弱でも自分の手番で発動し、CPUは最初の手番に使用する暫定判断。

- 破竹の勢いは配牌時だけでなく、局中の数牌変化にも適用する。共通の `changeTileKind` に局イベントを渡し、索子化後に赤牌・幺九牌限定効果の保持条件を判定する。

- 原典の `超次元麻雀 設計書 v0.1.md` に未確定事項がある。暫定設定と確定ルールを混同しない。
- 現在のアプリはローカル対CPUの試作版。完全なリーチ麻雀の点数・役判定ではない。
- 未実装の能力カードや特殊牌の効果を、実装済みと案内しない。
- 公開用の文章に開発上の注釈を混ぜない。
- 作業前に `docs/` を読む。変更後は `progress.md`、公開向け変更時は `patch_notes_public.md` を更新する。
- 全文書とコードを UTF-8 で保存する。PowerShell の文字列置換で日本語ファイルを更新しない。
- 牌画像はFluffyStuffのCC0素材を同梱。出典・固定コミット・利用条件は `assets_credits.md`、ライセンス原文は `public/assets/tiles/LICENSE.md` に保存。素材を差し替える際も出典と利用条件を確認する。
- 画像化しても牌名の代替表示、aria-label、赤ドラ・特殊牌・圧縮牌の印を維持する。公開された他家のトラップ牌は打牌まで正体を隠す既存ルールを保つ。
- 演出は描画の差分だけに適用し、ゲームの進行・乱数・待機時間へ影響させない。端末の `prefers-reduced-motion` と演出OFFを尊重する。伏せ牌には牌種を示す画像やデータ属性を出さない。
- 和了結果の牌画像は `Score.chosen` の採用結果を保存して表示する。虹色変化・多牌・刻子牌・圧縮牌を、元の手牌から再構築しない。刻子牌の仮想牌と圧縮牌の2枚目は印を付ける。通常の14枚へ無理に切り詰めず、n対子などの採用枚数を維持する。
- 和了点、翻、符、特殊牌、能力カードの用語を統一し、ヘルプにも説明を置く。
- 役一覧の「有効」は設定上使える役であり、現在の手牌で成立済みという意味ではない。「無効」は設定OFF、「対象外」は局イベントの進行・牌体系で使わない役を示す。ダブル役満OFFでは13翻へ戻し、役自体を無効化しない。表示用の状態判定で得点計算を変更しない。
- プレイヤーとCPUは副露可能。CPUはカン・ポン・チーの優先順位で鳴く暫定方式で、打点や待ちを考慮する高度な鳴き判断ではない。
- v0.2差分を原典に加える。踊り子の複合役抽選など未確定・未実装部分を実装済みと案内しない。
- v0.3差分も原典に加える。三人打ちと北抜きは暫定ルールで実装済み。正式な細部が未確定であることを記録する。トランプマジックでは1・13を么九牌として扱い、追加の刻子牌6枚は通常の特殊牌枠に含めない。
- v0.4差分も原典に加える。未確定事項がある効果は決め打ちせず、暫定実装と未実装範囲を進捗・要件に明記する。
- v0.4の「起家」は対局開始時の親で固定する。転調の発動判定と神経衰弱の開始席を、局ごとに移る親へ戻さない。
- 伝説の秘宝の役別成立条件はv0.4で未決定。出現数だけ先に対応しても得点効果のない牌を実装済みと案内しない。役ごとの条件と複合禁止を決めてから配布・得点へ接続する。
- 対子祭りの追加牌の抽選方法、圧縮牌を河へ捨てた場合の扱い、三連子そのものの翻数はv0.4で確定していない。実装する場合は暫定ルールを明記し、公開文面で確定仕様として案内しない。
- 神経衰弱のドラ・特殊牌配置方法と一部カードの使用可否も未確定。現在は全牌を伏せて配置し、ドラなし・得点系カードのみの暫定方式で実装している。
- 神経衰弱の終盤は、残り牌で面子・雀頭を作れる席へ進め、全席に候補がなければ終了する暫定方式。原典に終盤の詳細はない。
- 神経衰弱では獲得した面子と雀頭を固定して得点を判定する。刻子牌の追加刻子は獲得済みの組を壊すため、この局では使わない暫定方式。
- 三人打ちの転調は初期牌山を108枚のままにし、変化で現れた萬子2～8を有効な待ち牌にする。萬子ドラは最初の発動前に1萬↔9萬、発動後に1→2→…→9→1とする暫定方式。聴牌・立直・フリテン判定では、萬子2～8のうち現在の局に現れた牌種だけを待ち候補に含める。待ち牌の残存枚数までは考慮しない。
- 通常対局の手牌・操作は卓内、能力カードは卓の左下、自分の副露・カン・北抜きは右下に配置する。ツモ牌は物理IDで識別し、表示上は理牌済みの手牌へ混ぜず右端に間隔を空ける。内部の並び順と牌の表示順を混同しない。再描画でもツモ印と分離を維持し、得点判定や打牌対象のIDを変更しない。
- 説明がある牌や得点項目にtitle属性を重ねない。aria-labelで牌名を保持し、画面上の説明はゲーム内ポップアップに統一する。固定の高さでずらさず、実際の説明の高さから牌との間隔を確保する。
- 卓の常時表示は牌・局情報・持ち点・カードを中心にする。通常の打牌案内は省略しても、鳴き候補・選択枚数・立直・追加打牌・危機感知など判断に必要な案内を隠さない。伏せ牌に牌種を示すデータを出さない。
- 他作品の参考画像は配置の参考として扱う。背景やキャラクター等の画像素材をそのまま転用しない。
