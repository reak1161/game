# 実装要件と対応状況

原典はルートの `超次元麻雀 設計書 v0.1.md` と `docs/超次元麻雀 設計書 v0.2 差分.md`、`docs/超次元麻雀 設計書 v0.3 差分.md`、`docs/超次元麻雀 仕様書 v0.4 差分.md`。本書は現行実装の範囲を示す。

## 遊べる範囲

- ブラウザで1人対CPUの四人打ち・三人打ち。4局または8局を選択できる。
- 三人打ちは北抜きを手動または自動で行える。抜いた北の枚数を公開し、牌山から補充する。
- 配牌、ツモ、打牌、河、ドラ表示牌、流局、局の切り替え、順位表示。
- 通常形、七対子、国士無双の和了形判定。
- 立直、ダブル立直、一発、門前清自摸和、海底摸月、河底撈魚、槍槓、断么九、平和、役牌、一盃口、二盃口、三色同順、一気通貫、対々和、三暗刻、七対子、混全帯幺九、純全帯幺九、混老頭、混一色、清一色、国士無双、大三元、四暗刻、小四喜、大四喜、字一色、緑一色、清老頭、天和、地和。待ち形と基本符を判定。立直和了時は裏ドラを加算。
- 特殊牌はノックアウト、虹色変化、圧倒的無双、松竹梅、浄化牌、一期一会、純粋牌、ドラミングビートの和了時効果を一部実装。
- 能力カードは青天井、面前至上主義、お先に失礼、千変万化、借りパク、ものひろい、海底の釘、便乗、ダマスカス、多牌、先を見据える、ニアピン、亜空槓を実装。
- 流局時に聴牌料3,000点を精算。立直供託は次の和了者へ渡す。
- 局イベントは不使用・確率発生・毎局発生を選択可能。青天井、破竹の勢いを実装。
- ローカル役は人和、大車輪、大七星、十三不塔、四連刻を個別にON/OFF可能。
- 九蓮宝燈を実装。国士無双十三面待ち、四暗刻単騎、純正九蓮宝燈、大四喜のダブル役満を個別にON/OFF可能（初期設定ON）。
- 赤ドラを個別設定でON/OFF可能。ON時は5萬・5筒・5索を各1枚ずつ赤牌にする。
- プレイヤーは上家の打牌をチーし、他家の打牌をポン・明槓できる。ポン後は手牌の4枚目で加槓でき、他家は槍槓でロンできる。副露後の役と符を区別する。
- CPUもロンがない打牌に対してチー・ポン・明槓を選び、副露後の手番と嶺上牌を処理する。
- CPUも門前で聴牌できるときは立直を宣言し、立直後はツモ牌だけを打牌する。
- 借りパクで牌を奪われたプレイヤーは次の手番の追加ツモまで和了できない。立直中で聴牌が崩れた場合は立直を解除する。追加ツモにはそのプレイヤーのツモ予約を適用する。
- ダマスカスの責任払いは、門前かつ立直していない他家の和了で発動する。ロン・ツモとも所持者が全額支払う暫定方式。
- v0.2の特殊牌「イレギュラー」「ゾンビ」「運命の導き」を追加。イレギュラーは最初に場へ4枚現れた牌種へ変化する。ゾンビは打牌ごとに30%で選ばれた手牌を自身と同じ牌種のゾンビ牌へ変化させる。
- 能力カード「カウントダウン」「踊り子」「ロードローラー」「ランダマイザー」「役満ボディ」を追加。「亜空間」を「亜空槓」に改称。
- フィナーレを局イベントに追加。四人打ちは残り12牌、三人打ちは残り9牌から公開し、各牌で全員のツモ和了を判定する。同一プレイヤーの複数回和了を許可する。
- フィナーレの公開手番では、その席のツモ予約、立直後のツモ回数、カウントダウン、海底の釘、アルティメットリーチを処理する。予約で変化した公開牌を全員の和了候補とする暫定方式。
- 特殊役「同一色」「三同刻」「四同刻」を追加。三色同刻と上位関係を適用する。
- 能力カードの配布枚数を通常局とオーラスで別々に1～3枚から選択できる。同局内で同名カードは重複しない。
- v0.3の能力カード「危機感知」「流しマシンガン」「ポケットビスケット」「アルティメットリーチ」「スケスケルトン」を追加。ツモ予約はプレイヤーごとに管理する。
- CPUもロードローラーとポケットビスケットを使用する。ロードローラーの対象牌の選択は暫定的な手牌のつながり評価を使う。ポケットビスケットは既存のツモ予約中には発動しない。
- CPUも千変万化とランダマイザーを使用する。つながりの少ない通常牌を変化対象にする暫定判断で、変化後のツモ和了を判定する。
- CPUも借りパクとものひろいを使用する。借りパクの対象は持ち点が最も高い相手から選び、その手牌1枚をランダムに取る。ものひろいは手牌とつながる河の牌を選ぶ暫定判断。追加打牌はロン・鳴きの見送り後も続け、鳴きが成立すれば終了する。
- ものひろいで河から取られた牌は元の捨牌から除外する。ものひろい自体は鳴きに数えず、流し満貫の「河を鳴かれていない」条件を壊さない。
- 立直後のカウントダウン・アルティメットリーチのツモ回数は、借りパクの追加ツモを含め実際に引いた牌ごとに数える。
- 踊り子は最初の配牌を聴牌形にし、自分の通常ツモ番開始時にツモ前の手牌を別の聴牌形へ強制変化させる（v0.3）。打牌直後には変化させない。暗槓・亜空槓後の次の通常ツモ番では固定カンを残し、残りの手牌を変化させる。固定カン3組・4組では三槓子・四槓子も抽選候補にする。嶺上・北抜きの補充・フィナーレの公開ツモでは追加変化しない。
- 特殊牌「トラップ」「刻子牌」を追加。トラップ牌でロンすると和了者から打牌者へ和了点が移る。刻子牌は1枚で刻子を作り、1枚ごとに余る2枚を和了形から外す。複数枚の刻子牌も同時に使用できる。副露で使うと効果を失う。
- オープンリーチと流し満貫を追加。役満時の「役満のみ」「すべて加算」を対局開始時に選択可能。
- ロンと鳴きが同時に可能なときも、ロン・チー・ポン・カン・スキップからアクションを先に選び、複数の鳴き方がある場合は牌表示付きの候補から選択できる。同じ牌種でも特殊牌・赤ドラを使う組み合わせを選び分けられる。
- 対局中の設定タブで鳴きなし、カンなし、ツモ切り、自動理牌、自動和了を切り替えられる。特殊牌の詳細は手牌の牌にカーソルを合わせるか、タッチ端末でタップして確認できる。
- 和了画面で役と点数を順に表示し、変化した役には変更要因の説明を付ける。
- 和了画面では点数計算で採用された牌を画像で表示する。複数人ロン・便乗・先を見据える・フィナーレも和了者ごとの採用牌を保存する。神経衰弱も共通の段階表示を使い、「演出をスキップ」で全結果を表示できる。演出OFFと端末の動きを減らす設定では段階表示の待機を省く。
- 役一覧を翻数別タブに分け、実装済みの役に牌で示した構成例と成立条件を付ける。対局画面のページスクロールを抑え、ログとカード説明をポップアップから確認できる。
- 役一覧は役名を全タブから検索し、通常役・ローカル役・特殊役と有効状態で絞り込める。設定OFFを「無効」、神経衰弱やトランプマジックの進行・牌体系で使用しないものを「対象外」として理由を表示する。現在の設定に応じた三槓子・四槓子・ダブル役満の翻数を表示し、この局で有効な特殊役を上部から選択できる。
- 局イベント「トランプマジック」を追加。字牌を除き、各数牌に10～13を加える。9-10-11などの順子、13から1へのドラ、13面待ちに対応。通常の特殊牌枠とは別に6枚の刻子牌を加える。特殊役「超一気通貫」「十三連宝燈」を判定する。
- v0.4のトランプマジック数牌ボーナス符を追加。和了形の数牌に数字×100符を加え、局全体のカン回数が奇数なら革命、2回以上の偶数なら革命返しで2・3の符を変える。
- v0.4の能力カード「ハイリスクハイリターン」を追加。自身の和了点と、自身が放銃して直接支払う点数を3倍にする。他家のツモによる支払いは変わらない。
- v0.4の能力カード「鬼に金棒」「タンヤオ32000点」を追加。前者は得点に加える成立役数だけ最高翻役1つを倍化し、後者は2～5の数牌だけで断么九が唯一の成立役なら13翻へ変える。
- v0.4の能力カード「鳴くだけ大三元」「下克上」「なきむし」を追加。鳴くだけ大三元は配牌前に三元牌を各2枚確保する。下克上はオーラス最下位の和了で成立役を各13翻に変更し、なきむしは四副露・単騎和了で13翻を加える。下克上で役満扱いになった役には役満ボディの2倍も適用する。
- v0.4の局イベント「転調」を追加。起家（対局開始時の親）のツモ番開始時に巡数別確率で判定し、場と牌山の数牌を+1（9→1）へ変化させる。和了時は数牌1枚につき数字×100符を加える。
- v0.4の対局前ポップアップを能力カード・特殊牌・局イベント・特殊役・ローカル役・その他のルールの6カテゴリへ拡張。特殊役7種のON/OFFを得点判定に反映し、対応する踊り子の変化候補からも無効な役を除く。
- v0.4の能力カード「対子祭り」を追加。手番で同じ牌2枚を圧縮牌1枚へ変え、牌山を減らさずに通常牌を1枚生成する。同じ手番で何度でも使え、CPUも圧縮可能な対子が続く限り使用する。圧縮牌は和了判定で対子2枚として展開し、通常形の雀頭と七対子から十四対子までの対子形を評価する。
- v0.4の連子形を追加。連続する同種数牌4枚を1組として、3組と雀頭で和了する。一色三連は3翻、三連子は暫定1翻で計算し、通常形と両方成立する牌姿は和了点が高い解釈だけを採用する。対局前に個別ON/OFFできる。
- v0.4の局イベント「神経衰弱」を追加。各局は起家（対局開始時の親）から始め、裏向きの牌から手番ごとに3枚をめくり、順子・刻子なら獲得する。4面子の後は2枚で雀頭を集め、14枚完成時にツモ和了として最終和了点を3倍にする。役判定は獲得した4面子と雀頭に固定し、同じ14枚でも別の面子構成や七対子など別の完成形へ読み替えない。最後の雀頭は両面待ちではないため平和を付けない。通常の配牌・打牌・鳴き・ロン・立直は行わない。

## 牌の表示と演出

和了・流局の結果では、局開始時から各席の持ち点がいくら変わったかを現在の持ち点と併せて表示する。立直供託や聴牌料を含み、段階演出の完了またはスキップ後に確認できる。

表示面では通常牌34種・赤ドラ3種を同梱のSVG画像で描画する。10～13は数字と種類による拡張表示。ツモ・打牌・変化・神経衰弱の公開・和了結果には差分演出を用意し、開始画面／通常対局の設定からOFFにできる。端末の動きを減らす設定を優先する。画像を読み込めない場合は牌名を表示する。

## 現在使えないルール

ニアピンは連子形の「一色三連まであと1面子」にも対応する。2連子が同じ種類で一色三連が有効な場合に判定し、三連子との複合を避ける。

- 役と符の完全な競技麻雀準拠判定。和了状況に依存する役や一部の特殊形は未実装。
- ニアピンの「あと1面子」判定は断么九・平和・対々和・三暗刻・四暗刻・三槓子・四槓子・四連刻・三色同順・三色同刻・三同刻・四同刻・同一色・一気通貫・一盃口・二盃口・混全帯幺九・純全帯幺九・混老頭・清老頭・混一色・清一色・字一色・緑一色・小三元・大三元・小四喜・大四喜に対応し、その他の役は今後拡張。
- 追加のローカル役、特殊役、オンライン対戦。
- 踊り子の全役を対象にした抽選と役の複合抽選。現在は通常の45種とトランプマジック専用の超一気通貫1種から役別聴牌形を生成し、局イベントに適した形だけを採用する。破竹の勢いでは全数牌が索子になるため、三色同順・三色同刻を基準役から除く。さらに各候補の待ち牌で和了点を試算し、基準役が実際に成立する候補だけを抽選する。
- v0.4の特殊牌「伝説の秘宝」。神経衰弱は専用の牌めくり進行と和了計算を実装済みだが、ドラ配置と一部カードの扱いは暫定。対子祭り、連子形と一色三連、七対子から十四対子までの対子形、対局設定の6カテゴリ個別選択、転調、トランプマジックの数牌ボーナス符・革命・革命返しと他のv0.4能力カードは対応済み。

## 暫定設定

- スケスケルトンの取得予定は現在の席順と、借りパクによる既知の追加ツモを反映する。予約は実際の変化処理と同じ牌種で表示する。将来の鳴き・カン・北抜き・転調発動までは予測せず、状態変更後の再描画で予定を更新する。フィナーレの公開手番には通常局の追加ツモを挿入しない。

- 踊り子の通常テンプレート候補は種類の入れ替えに加え、数字反転（通常1↔9、トランプ1↔13）でも生成する。聴牌・目標役・牌体系・固定カンの条件を満たす候補だけを採用し、同じ役の同じ牌姿は重複させない。全役・全牌姿の生成と複合役抽選は未実装。

- 踊り子はトランプマジックの十三連宝燈にも条件付きで対応。刻子牌2枚以上・固定カンなし・圧縮牌なし・役設定ONで、両端の刻子牌を保持した13面待ちを候補に追加する。圧縮牌偶数枚・固定カンなしでは八対子〜十三対子の候補にも対応する。

- 千変万化は通常局で1～9の筒子、トランプマジックで1～13の筒子から等確率で選ぶ。破竹の勢いでは同じ数字の索子になる。プレイヤーとCPUは同じ抽選処理を使用する。

- ニアピンは通常局・神経衰弱ともプレイヤーが自分の手番に任意発動する。CPUは最初の手番で発動する暫定判断。

- 三人打ちの転調で萬子2～8を待ち牌として扱うのは、その牌種が現在の局に存在する場合に限る。局内の残存枚数は判定しない。

- 初期持ち点: 100,000点（50,000点に変更可能）。飛び終了なし。
- 特殊牌: 1局5枚（4枚・8枚・12枚に変更可能）。各枠独立抽選で同名の重複あり。
- 能力カード: 通常局・オーラスで別々に1人1～3枚。局ごとに再配布。同局内で同名の重複なし。踊り子と多牌は手牌枚数が衝突するため同じ人へ配らない。
- 複数人ロン時の立直供託は、打牌者から時計回りで最も近い和了者へ渡す。
- 青天井は所持者の和了点に適用。
- 局イベントを「ときどき」にした場合の発生確率は35%。発生時は有効化したイベントから等確率で選ぶ。
- フィナーレ終了後は流局時の聴牌料を精算する暫定方式。
- ダマスカスの責任払いは、ロン・ツモとも所持者が全額支払う暫定方式。
- 暗槓では嶺上牌・槓ドラ・裏槓ドラを牌山の末尾から取得する。三槓子は役満、四槓子はダブル役満を初期設定とする。
- ローカル役5種は初期設定で無効。人和は初巡の非立直ロン、十三不塔は初回ツモ時の孤立牌形で判定する暫定方式。
- 赤ドラは初期設定OFF。牌変化では赤牌を新たに作らず、元の赤牌が変化後も5牌なら赤を維持する。
- プレイヤーには鳴きの選択を提示する。CPUはカン、ポン、チーの順に実行可能な鳴きを選ぶ暫定方式。
- 流しマシンガンとポケットビスケットのツモ予約が同時に発生したときは、後に発動するポケットビスケットを優先する暫定方式。
- その後の打牌で新しいツモ予約が生じた場合は、未消化の予約を上書きする暫定方式。両カードをまたぐ予約の優先順位は原典に確定した詳細がない。
- 三人打ちの牌山は萬子2～8を除く108枚の暫定方式。赤5萬はなく、トランプマジック中はイベントの1～13牌体系を優先する。転調では初期牌山は108枚のまま、変化で生じた萬子2～8を聴牌・和了候補に含める。萬子ドラは最初の転調が発動するまでは1萬と9萬の循環、発動後は1→2→…→9→1の数字循環で判定する暫定方式。ツモ和了は相手2人が支払い、不足分の補填はない。北抜きは牌山から1枚補充し、抜いた北1枚につき1翻を加える。役満のみの設定では加算しない。北抜きの扱いは設計書に細部がないため暫定方式。
- 鬼に金棒で最高翻の役が同値なら、得点判定で先に追加した役を選ぶ暫定方式。役満のみ設定では計算に残る役満役だけを成立役数に数える。
- 下克上の最下位は同点者を含む暫定方式。トランプマジックには三元牌がないため、その局では鳴くだけ大三元を配布候補から外す。
- 転調の「起家」は対局開始時の親で固定する。牌山の数牌も場にある牌として変化させる暫定方式。
- 対子祭りで追加する牌は通常牌から等確率で独立生成する暫定方式。圧縮牌は元の2枚の特殊効果と赤ドラを保持し、通常和了形では圧縮牌を分割せず2枚まとめて採用する。圧縮牌を打牌したときは保存していた2枚目を除き、河では通常の1枚として扱う。圧縮牌をチー・ポン・カン・北抜きに使わない。これらは原典に詳細がないため暫定。
- 三連子そのものの翻数は原典にないため、1翻で計算する暫定方式。一色三連が成立する場合は三連子と翻を重ねず、一色三連3翻を採用する。既存の3枚組の副露は連子組として扱わない。
- 神経衰弱のドラ・特殊牌の配置方法は原典未確定。暫定的に牌山相当の全牌を盤面に伏せ、ドラ表示牌とドラ加算を使わない。能力カードは和了形・得点だけに作用するものから配布し、ハイリスクハイリターンや牌操作カードは配布しない。CPUは見た牌を記憶し、完成済みの面子・雀頭を優先する。完成組がなくても、記憶した2枚で面子を狙えるならその2枚と未知の1枚を選ぶ。残り牌から面子・雀頭を作れない席は飛ばし、どの席も作れなければ局を終了する。刻子牌は追加の刻子を作らず、獲得した面子内の通常牌として扱う。
- 神経衰弱の特殊牌は設定で有効な種類のうち、虹色変化・松竹梅・浄化牌・一期一会・純粋牌だけを配置する暫定方式。通常ツモや打牌を必要とする特殊牌は配置しない。
- 神経衰弱では赤ドラ設定がONでも赤牌を配置しない。通常局の赤ドラ設定は維持する。
- 神経衰弱で4面子＋雀頭を完成させても役がなければ和了せず、14枚の席は追加の雀頭を獲得しない。ほかの席に成立可能な組があれば続行する暫定方式。
- v0.4の対局前設定では、能力カード・特殊牌・局イベント・特殊役・ローカル役・その他のルールを個別にON/OFFできる。全選択・全解除・デフォルト・名前検索・詳細表示を備える。ルーム対局は未実装。

## 用語

- **連子**: 同じ種類の数牌4枚が連続した組。通常の3枚の順子とは別の和了形で使う。

- **和了点**: 和了によって移動する点数。
- **翻**: 役・ドラの点数倍率に関係する値。
- **符**: 和了形に応じた点数要素。
- **特殊牌**: 通常牌の性質に追加効果を持つ牌。
- **能力カード**: 局ごとに配られるプレイヤー固有の効果。
- **副露**: 他家の打牌を使ってチー・ポン・明槓をすること。副露後は門前の役を得られない。
- **北抜き**: 三人打ちで手牌の北を公開して脇に置き、牌山から1枚補充すること。現在は1枚につき1翻。
