# ヴィラニス / VILLANICE

「ヴィラン + アイス」をモチーフにした、3Dの非対称サバイバルホラーゲームです。氷に閉ざされた収容所で、4人の生存者と氷の番人が対峙します。**生存者は背後からのTPS、番人は一人称のFPS**で開始します。どちらもVキーで視点を切り替えられます。

## 起動

`index.html` をWebGL 2対応の Chrome / Edge で開くと遊べます。3D描画用のThree.jsを含むビルド済みファイルを同梱しており、プレイ時のネット接続・インストールは不要です。

「氷獄の中へ」をクリックするとマウスで視点を操作できます。Escでマウスを解放して一時停止します。マウスを取得できない環境では、画面のボタンをクリックするか右ドラッグで視点を操作してください。

ローカルサーバーを使う場合（Node.js 18以上）:

```powershell
cd D:\programming\game\villanis
npm start
```

ブラウザで http://localhost:4173 を開いてください。別のポートを使う場合は環境変数 `PORT` を設定します。

## ゲーム内容

- **生存者**: 自分とAI3人。5台の熱源装置のうち3台を修理し、左右いずれかの氷の門を7秒間かけて開放、門に近づいて脱出します。
- **氷の番人**: 自分対AI4人。攻撃2回で生存者を氷牢へ収容。各生存者は捕獲3回か氷牢の55秒経過で脱落。最終的に3人以上収容で勝利、2人なら引き分けです。
- **氷霧と索敵**: 生存者の氷霧は6秒間視界を遮り、28秒で再使用可能。番人の「凍てつく反響」は5秒間全員の位置を表示し、24秒で再使用可能です。
- **チェイス**: スタミナを使うダッシュ、足跡、しゃがみ、壁による視線遮断、板倒しによる3秒スタン、板の破壊。
- **3D操作**: マウスによる水平・垂直の視点操作、カメラ方向に合わせた移動、肩越しのTPSカメラ、壁際でカメラを手前に寄せる衝突処理、正面かつ視線の高さにいる相手への近接攻撃。
- **協力**: 氷牢からの救助、仲間の治療、救助直後の7秒間の保護。
- **修理判定**: 修理中、白い範囲でSPACEを押すと進捗ボーナス。失敗すると進捗が戻り、番人に音が届きます。
- **制限時間**: 7分。時間切れの生存者は収容扱いです。生存者プレイでは自分の脱出または脱落で終了します。

## 操作（PCキーボード・マウス）

| 操作 | キー |
|---|---|
| 視点操作 | マウス（取得できない場合は右ドラッグ） |
| 視点方向に合わせた移動 | WASD / 矢印 |
| FPS / TPS切替 | V |
| TPSの左右の肩を切替 | B |
| 地図の表示・非表示 | M |
| ダッシュ（生存者） | Shift |
| しゃがみ（生存者） | C / Ctrl |
| 修理・救助・治療・門の開放 | E 長押し |
| 板倒し / 修理判定（生存者） | Space |
| 攻撃（番人） | 左クリック / Space。正面の近い相手を狙います |
| 板・熱源装置の破壊（番人） | E 長押し |
| 氷霧 / 凍てつく反響 | Q |
| 一時停止 | Esc |

他のタブやウィンドウへ移動すると自動で一時停止します。マウス感度は一時停止画面で変更できます。サウンドは画面上のボタンで切り替えられます。

## 構成・検証

`engine.js` はゲーム処理と経路探索、`controls.js` は視点方向に合わせた移動計算、`game.js` は入力・効果音・UIです。`src/renderer3d.js` はThree.jsによる3D描画・キャラクターの歩行アニメーション・FPS/TPSカメラ・陰影・降雪を担当します。効果音はWeb Audioで生成しています。

描画コードを変更した場合は `npm run build` で同梱用の `renderer3d.js` を更新してください。開発依存関係のインストールにはネット接続が必要です。

```powershell
npm ci
npm run build
npm run check
npm test
npm run test:browser
```

ブラウザテストはインストール済みのChromeを使用します。他のChromium系ブラウザを使用する場合は環境変数 `BROWSER_PATH` に実行ファイルのパスを設定してください。テスト結果のスクリーンショットは `artifacts/` に保存します。

現状はローカルシングルプレイの3Dプロトタイプです。オンライン対戦・スマートフォン向けタッチ操作は実装していません。既存作品のキャラクター・マップ・画像・音声は使用していません。Three.jsのライセンスは `LICENSE.three.txt` に同梱しています。
