# 開発進捗

## 2026-08-08

- 設計書 v0.1 を確認。
- 5人固定・同一ブラウザで交代操作する試作版の画面を新規作成。
- 初期ライフ、初期手札、手札上限、5種類のターン行動を実装。
- 基本の爆弾配置、配置位置選択、導火線追加、着火、消火、延焼、爆発を実装。
- 「ばくだん」「れんさぼむ」「だぶるぼむ」「ちゃっかだん」「どうかせん」「ひうちいし」「おうきゅうしょち」「しょうかき」「ぼうかん」「ちょっとかんがえる」を試作デッキに追加。
- 敗北判定、生存プレイヤーの手番スキップ、通常勝利判定を実装。
- 5人分の盤面、手札、山札、捨て札、ラウンド、ゲームログ、遊び方を表示するレスポンシブUIを作成。
- Cloudflare Workers Static Assetsでフロントエンドを配信する構成へ移行。
- 1ルームにつき1つのDurable Objectを使うオンラインルーム基盤を追加。
- 6文字の参加コード、最大5人の参加、ホスト表示、接続状態、再接続、ホストによる開始をWebSocketで同期。
- Durable Objectのルーム状態をSQLiteへ永続化。
- `bakudan.reak1161.com` をカスタムドメインとしてWranglerへ設定し、Workerをデプロイ。
- TypeScript型検査、Workerのドライラン、Worker起動時間の確認を実施。
- オンラインゲームの山札、手札、ライフ、爆弾、導火線、着火状態、手番、ラウンド、ログをDurable Object側へ移行。
- 各接続へ専用の表示状態を配信し、自分以外の手札内容を非公開化。
- 5種類のターン行動と基本カード10種をオンライン操作に対応。
- カード対象と手番をサーバー側で検証し、延焼、爆発、通常ダメージ、敗北、勝利をサーバー側で処理。
- 本番環境で2クライアントの参加、開始、初期手札、2枚ドロー、手番移動、リアルタイム同期を自動確認。
- オンライン版の対象選択をポップアップ式から盤面クリック式へ変更。
- 選択可能な手札、プレイヤー、爆弾を強調表示し、爆弾の配置可能位置に「＋」ボタンを表示。
- ゲームログを上が古く下が新しい順に変更し、更新時に最新ログへ自動スクロール。
- 「2枚使う」を二段階処理へ変更し、1枚目の効果をサーバーで解決・全端末へ同期してから2枚目を選択するよう修正。
- 本番環境で1枚目の「れんさぼむ」配置後に手札4枚・爆弾1個へ更新され、その更新後の爆弾へ2枚目の「ひうちいし」を使用して手番が進むことを確認。
- 1人テストをDurable Object上の5人テストルームへ移行し、オンライン対戦とゲーム処理・UIを共通化。
- ブラウザ内に重複していた旧ローカルゲーム処理を削除。
- 本番環境で1人テストルームの5人生成、現在手番の手札表示、「2枚引く」、次プレイヤーへの操作切り替えを確認。
- 「1枚引いて使う」の使用段階と「2枚使う」の2枚目で、途中ボタンを押さず自動的に手札選択へ進むよう変更。
- 続きの使用段階では、その時点で使用条件を満たすカードだけを選択可能として表示。
- 手札と盤面の爆弾へカーソルを合わせたとき、カード効果を表示するツールチップを追加。
- 山札クリック時に、山札の実残枚数とカード別の残り候補を表示する一覧を追加。
- カード別の残り候補は初期投入枚数から自分の手札と公開済みの捨て札だけを差し引いて計算し、非公開情報を送信しない設計にした。
- 本番環境で捨てたカードの種類と捨て札枚数が公開状態へ反映され、山札一覧UI用の集計情報が取得できることを確認。
- 背景、主要パネル、カード、ログ、ダイアログのベースカラーをペールグレー／ライトグレー系へ変更。
- 着火、選択状態、山札などの識別に必要なくすんだオレンジはアクセントカラーとして維持。
- 延焼・爆発の進行対象を全プレイヤーの爆弾から、手番を終了したプレイヤーの前にある爆弾だけへ変更。
- ゲーム仕様書と画面内の遊び方を新しい延焼タイミングへ統一。
- 本番環境でプレイヤー1がプレイヤー2へ置いた「ちゃっかだん」の導火線がプレイヤー1のターン終了時には進まず、プレイヤー2のターン終了時に1段進むことを確認。
- 毎ラウンド終了時に7種類から1つをランダムに選ぶラウンドイベント処理を追加。
- 「全員着火」「スワップ」「ライブラリメテオ」「薄れる記憶」「ひょっこりぼむ」「大逆転」「綿密な調整」を追加。
- ラウンドイベント名と効果を全端末の盤面・ゲームログへ同期するようにした。
- 補充は手札上限7枚と山札残枚数の範囲、廃棄は現在の手札枚数の範囲で処理するようにした。
- 型検査とWorkerのドライランを通し、`bakudan.reak1161.com` へ試作版0.6.0をデプロイ。
- 本番の1人テストで5人分のターン終了後にラウンド2へ進み、「綿密な調整」が発生して全員の手札が7枚まで補充されることを確認。
