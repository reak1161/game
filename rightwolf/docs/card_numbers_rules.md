# 猟師の鋏：数値参照

2026-10-12のユーザー回答に基づき、攻撃値・防御値だけでなく、設計書のカード効果本文にある数値を合算する。

- 対象人数、回数、枚数、期間、HP、倍率、%補正、条件の閾値など、本文に記載された算用数字を対象にする。
- 同じ数値の繰り返し記載もそれぞれ数える。%表記は記載された数字（100%なら100）、分数はその値（1/2なら0.5）、符号付き補正は符号を保持する。
- 範囲「1〜5」は記載されている1と5を数え、間の2・3・4を補わない。
- カード名のLV、章番号、収録枚数の見出し、計算例、Web UIの手順番号は効果本文に含めない。算用数字のない「半分」「一度」から数値を推測して追加しない。
- 合計÷2を切り捨てて基礎攻撃値とする。負なら0。通常の攻撃力補正・防御・軽減はその後適用する。
- 短縮表示用の効果説明を自動解析しない。`src/game/card-numbers.ts` に元本文の数値の出現を記録する。新カードや本文変更時は数値データとテストも更新する。
