# 忘れてはならない事項

- 作業前に `docs/`、特に要件・アーキテクチャ・公開パッチノート規約を読む。
- 変更ごとに `progress.md` を更新する。
- 公開向けの変更は `patch_notes_public.md` も更新する。
- 文書とUIの文字コードはUTF-8を維持する。PowerShellの一括置換で日本語ファイルを書き換えない。
- 「通常ダメージ」と「ライフ減少」を混同しない。初期版では「固定ダメージ」「特殊ダメージ」という未定義語をUIに出さない。
- 「全員」は使用者自身を含み、使用者から席順に処理する。
- 成立済みの効果は、処理中に使用者が死亡しても最後まで解決する。
- 親はゲーム中固定。v0.3では2フェーズ終了ごとに昼夜を切り替える。追加ターンはフェーズを進めず、即時反転は周期をリセットしない。
- 死亡・仮死状態のプレイヤーは対象にできず、行動できない。設置カードは場に残るが基本的に無効。
- 未確定仕様を推測で確定しない。暫定挙動を入れる場合は要件と進捗に明記する。
- 公開UIに開発者向け注釈やファイル説明を混ぜない。
- オンライン対戦が前提。同一端末の受け渡しを要求するUIへ戻さない。
- 秘密情報はUIで隠すだけにせず、所有者以外のクライアントへ送信しない。
- ゲーム状態の正本とルール判定はサーバーに置き、クライアント申告のプレイヤーIDや状態を信用しない。
- ブラウザには再接続用の部屋コードとトークンだけを保存し、手札や伏せ役職を保存しない。
- 1人用テストは通常対戦と区別し、勝利判定を行わない。2人以上の勝利条件を緩めない。
- v0.2では「誰か1人」に自分も含む。1人用テストでも自己攻撃を可能にし、旧版の自己攻撃禁止へ戻さない。
- v0.2の保留6種類8枚は継続。v0.3の追加36枚はすべて収録し、両セット使用時は93枚。白夜の斬撃は基礎値3、猟師の鋏は本文の数値全合算でユーザー確定済み。
- COと強制開示を区別し、強制開示で通常のCO時能力を再発動しない。
- 設置防御は任意の1ヒット発動。防御値の合算消費に戻さない。トラップは防御で0ダメージになった後も発動可能。
- サーバー内の処理キュー・保留カード・他人の選択肢をクライアントへ送らない。選択IDは各段階で更新し、本人以外・重複・古い回答を拒否する。
- 自分の手番外でも誘発の選択に応答できること。CPUも応答し、人間の選択待ちではCPUを進めない。
- 残虐な猶予は発動者死亡後も残す。期間効果の期限は親の位置ではなく所有者のターン回数で管理する。
- ユーザー追加の扇状手札・Pointer Events・550msホバー・配札・被弾・CO・捨て札の有限アニメーションと動き抑制対応を保持する。
- 選択は盤面の実物を優先する。手札・対象の席／役職・期間効果を直接選び、山札・捨て札は卓内の候補列へ展開する。全面モーダルやプルダウンへ戻さない。
- PC向けを優先する。カード追加・選択開始で盤面の寸法や席／自分のHPの位置を変えない。ウィンドウに収まる固定配置とし、候補多数の場合はカード列内だけスクロールする。
- 合計防御値を表示しない。設置カードごとの条件と継続効果を表示する。被弾演出は実際のHP減少で発生させる。
- 変動する攻撃値は現在の発言数・手札・選択数値・対象等から実際の計算と共通化して表示する。対象の防御・軽減前の値とし、未選択の対象や保留ルールを推測しない。
- 捨て札一覧に効果説明を常設しない。ホバーの説明を使う。手札の持ち上がりはホバー・選択中のみで、フォーカスだけでは移動させない。選択番号は複数選択の場合だけ表示する。
- 卓内の選択欄に長い説明や同一の結果を繰り返し並べない。詳細は効果元カードのホバー／クリック、枚数でまとめられる結果は集約し、文章を読むための縦スクロールを避ける。
- 設置防御の発動は全面モーダルにせず、自分の場からカード候補を拡大して並べる。効果元の画像・今回の1ヒットの結果・山札付近の「発動する／使用しない」を表示する。トラップは反撃であり、元のヒットを防ぐと案内しない。
- 選択の効果元は公開済みカード／役職だけを引き継ぐ。結果プレビューはサーバーで実際の軽減・護衛を反映し、本人だけへ配信する。表示用sourceCardを処理用cardの代わりに使って、発言無効化や捨て札処理を変えない。
- 手札選択時のクリックと通常使用を混同しない。選択可能カードだけを受け付け、サーバーの選択ID・枚数・回答者検証と秘密情報の境界を維持する。
- 操作を何でも文章で表現しない。「使用先を選ぶ」ボタン、常設のドラッグ／ホバー説明、ドラッグ中の案内文、カード説明内の操作ヒントは出さない。対象は枠・照準・強調で示す。カード効果や必要な確定操作まで削除しない。
- 猟師の鋏の計算を短縮UI説明の正規表現解析にしない。本文用の数値データを更新し、本文の範囲・符号・分数・重複記載はcard_numbers_rules.mdに従う。裏向き候補にはUIDやカード内容を渡さない。
- 赤ずきんの復活は死亡世代を変える。同じ連続攻撃の残りを復活後へ再開しない。
- 純愛者の生存人数除外、死亡後の勝利リンク、複数勝者一覧を維持する。死亡と効果そのものの剥奪を区別する。
- ターン内の履歴は実際のHP変化を使い、次の通常／追加ターン開始時にリセットする。攻撃力補正の再適用と、白夜の斬撃の実ダメージ参照を混同しない。
