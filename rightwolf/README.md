# ライトウルフ

各プレイヤーが別の端末・ブラウザから参加して遊ぶ、オンライン対戦対応のWebカードゲームです。

## 起動

```sh
npm install
npm run dev
```

Web画面は `http://localhost:5173`、ゲームサーバーは `http://localhost:8787` で起動します。同一LANの別端末から試す場合は、両方のポートへ接続できるようにしてホスト名を置き換えてください。

本番用ビルド後は次のコマンドで、画面とWebSocketサーバーを同じポートから配信できます。

```sh
npm run build
npm start
```

## 検証

```sh
npm run check
```

単体テストと本番ビルドをまとめて実行します。

## 現在の範囲

開発版 0.3.0 では、2〜6人のオンライン対戦、CPU対戦、1人用テストに対応しています。基本セットの確定済み57枚に「眠りの森」13枚・「血塗れの赤い月」23枚を追加し、両追加セット使用時は93枚です（基本セットの未確定8枚は保留）。待機室で追加セットを選べます。昼夜2フェーズ周期、追加ターン、復活、特殊勝利、対象変更・反撃などに対応しています。詳しい範囲と保留事項は `docs/requirements.md` と `progress.md`、猟師の鋏の数値集計は `docs/card_numbers_rules.md` を参照してください。

`node scripts/cpu-smoke.mjs` は独立した一時サーバーでオンライン・CPU・秘密情報・選択待ち中の再接続を検証します。既存の開発用部屋には影響しません。
